## v0.2 — Server deploy from the repo

### AGORA-003 — Write server/deploy.sh (preflight, sync, apply, verify, --dry-run)

**Description:**
A bash script, the only path by which `server/` reaches the Ubuntu host. Reads `server_con.yaml` for
host/user; key auth only (one-time `ssh-copy-id` fallback if keys fail — already satisfied on this host).

**What needs to be done:**
- Parse `server_con.yaml` (host, user) without ever reading the password into argv, output or logs; the
  password is used only by the interactive `ssh-copy-id` fallback, typed by `ssh-copy-id` itself.
- Preflight: `REGISTRATION_TOKEN=dummy docker compose -f server/docker-compose.yml config -q`; abort on failure.
- Key check: `ssh -o BatchMode=yes` probe; on failure run `ssh-copy-id` (interactive) once, then re-probe.
- Sync: `rsync` `server/docker-compose.yml` (always) and `server/.env` (only if present locally) to
  `~/matrix-agora/server/`; never delete or overwrite the host's `.env` when there is no local one.
- Apply: `ssh <host> 'cd ~/matrix-agora/server && sudo -n docker compose up -d || docker compose up -d'`.
- Verify: poll `http://<host>:8008/_matrix/client/versions` (bounded retries, ~60 s budget); clear
  success/failure report, non-zero exit on failure.
- `--dry-run`: print the preflight result and what would be synced/run (`rsync -n`), change nothing.
- Idempotent: a re-run with no changes only verifies.

**Dependencies:** None

**Expected result:**
One command moves the repo's server config to the host and proves the homeserver still answers.

**Acceptance criteria:**
- [ ] Preflight, key check, sync, apply, verify and `--dry-run` behave as described
- [ ] The password never appears in argv (`ps`), output or logs; `bash -x` paths don't leak it
- [ ] **Gates:** compose (the preflight itself) · `bash -n server/deploy.sh` clean · lint/tests n/a (pre-v0.5)

### AGORA-004 — Prove the deploy loop against the live host

**Description:**
Run the v0.2 DoD against the real host: a comment-only compose change travels through `deploy.sh`, and
`--dry-run` is shown to change nothing.

**What needs to be done:**

- Add a comment line to `server/docker-compose.yml` (committed), run `server/deploy.sh` → file lands on the
  host, compose re-applies, homeserver answers.

**Dependencies:** AGORA-003

**Expected result:**
