# v4.4 — Issues

Issues for phase **v4.4 — Claude on the subscription: answering when asked** (version **v4 — Ensemble**), derived
from the Tasks and DoD in [ROADMAP.md](../ROADMAP.md) §v4.4 and the contracts in [ARCHITECTURE.md](../ARCHITECTURE.md).
This file covers one phase; ids continue from the previous phase (AGORA-058 → **AGORA-059…064**).

Claude joins Agora as itself — «Клод», no canon, no memory — and answers in Ukrainian (owner, 2026-10-10) when
someone names him, running only on the owner's Max subscription through the Claude Agent SDK; an API key can never
be used. It builds on v4.1's roster, `Responder` seam and modes, v4.2's outgoing guard, and v4.3's review fixes;
the philosopher mode and `ranked` turn-taking are v4.5.

**Reconciled with the SDK** (`claude-agent-sdk` 0.2.165, bundled CLI 2.1.294, read 2026-10-10): `query(prompt=…,
options=ClaudeAgentOptions(…))` yields `SystemMessage` (subtype `init`, `data`), `AssistantMessage`, `RateLimitEvent`
(`rate_limit_info`: `status` allowed / allowed_warning / rejected, `resets_at`, `rate_limit_type`, `utilization`) and
`ResultMessage` (`is_error`, `result`, `stop_reason`, `usage`, `total_cost_usd`, `api_error_status`). The options
used: `system_prompt`, `tools=[]` (all built-in tools off), `disallowed_tools`, `permission_mode="dontAsk"`,
`setting_sources=[]`, `mcp_servers={}`, `max_turns=1`, `model`, `env`, `cwd`, `effort`. The init message's
`apiKeySource` is `"none"` when only the OAuth token authenticates; the CLI's other values are `ANTHROPIC_API_KEY`,
`apiKeyHelper` and `/login managed key`.

### AGORA-061 — `ClaudeSdkResponder`, the no-API-key layers and the rate-limit breaker

**Description:**
One stateless `query()` per reply on the subscription, with every layer that keeps an API key out, and silence at
the subscription's limits. Touches a new `agents/claude_sdk.py`, `agents/responder.py`, `agents/agent.py`,
`pyproject.toml` (an optional `claude` extra), ARCHITECTURE and the tests.

**What needs to be done:**
- **The forbidden set:** `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL`, any `CLAUDE_CODE_USE_*`,
  `CLAUDE_CODE_SIMPLE`. **Startup refuses** (exit, naming the variables, never their values) when one is set or
  `CLAUDE_CODE_OAUTH_TOKEN` is missing; the forbidden names are also **scrubbed** from `os.environ` before the first
  `query()`.
- **`ClaudeSdkResponder`:** the options (`system_prompt` = the brief, `tools=[]`, `disallowed_tools` = Bash, Read,
  Write, Edit, Glob, Grep, WebFetch, WebSearch, Agent, Skill, `permission_mode="dontAsk"`, `setting_sources=[]`,
  `mcp_servers={}`, `max_turns=1`, `model=CLAUDE_MODEL` (`opus`), `cwd` the config dir, `env` with
  `CLAUDE_CODE_MAX_OUTPUT_TOKENS`, `CLAUDE_CODE_SKIP_PROMPT_HISTORY=1`, `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` and the
  tmpfs `CLAUDE_CONFIG_DIR`); the prompt is the `"Name: text"` transcript of `HISTORY_N` lines; the text from
  `ResultMessage.result` (else the assistant's text blocks); `stop_reason == "max_tokens"` → `finish = max_tokens`;
  `is_error` → silence (logged with `subtype` and `api_error_status`, never text).
- **The init check:** `apiKeySource` must be `"none"` and the tool list empty; anything else blocks every later reply
  (logged with the source name).
- **The rate-limit breaker:** `RateLimitEvent` `allowed_warning` → muted until `resets_at`; `rejected` → silent until
  `resets_at`; the last event goes to `state/<name>.ratelimit.json` (`status`, `utilization`, `resets_at`,
  `rate_limit_type`, `muted_until`, `auth`, `updated_at` — no texts, no token; atomic, 0600).
- **Accounting:** each call writes a v2 usage line — `claude-sdk`, `subscription`, the result's tokens, cache tokens
  and `total_cost_usd` as `reported_cost_usd` — never `api`.
- **No API client in the code:** the SDK is imported lazily inside the responder; no `anthropic` import anywhere; the
  package is an optional `claude` extra (the tests mock `query`).

**Dependencies:** AGORA-059, AGORA-060

**Expected result:**
Claude answers through the SDK on the subscription only, and stays silent at a limit or on any sign of an API key.

**Acceptance criteria:**
- [ ] Startup refuses for each forbidden variable and for a missing OAuth token, naming only the variable.
- [ ] A mocked `query()`: success → the text and a `subscription` usage row; `is_error` → silence; `max_tokens` →
  trimmed; an init with another `apiKeySource` or a tool → blocked; `allowed_warning` / `rejected` → muted until
  `resets_at`, recorded in the state file.
- [ ] The forbidden names are absent from the environment the SDK sees.
- [ ] **Tests:** `tests/test_claude_sdk.py` (all of the above, the options, the import set of `agents/` — no
  `anthropic`, the SDK only inside the responder).
- [ ] **Contract:** env names (`CLAUDE_MODEL`, `CLAUDE_CODE_OAUTH_TOKEN`, `CLAUDE_CODE_MAX_OUTPUT_TOKENS`, the
  forbidden set) and the state file `<name>.ratelimit.json` — ARCHITECTURE §Configuration, §Data and state files,
  §Security and §Contracts updated, pinned by `tests/test_claude_sdk.py`.
- [ ] **Gates:** lint · tests.
