## Findings

### 1. 🟠 Lost Element lines after a restart
**Where:** `agents/agent.py` `start_private` and `seed_private_from_archive`.

**Scenario:** during a deploy the owner writes in the Element private room.
- At start, `start_private` reads that line from the homeserver into the history but does not archive it.
- `seed_private_from_archive` then replaces the history with the archive's lines.

The line is gone from her context and is never archived.

**Fix:**
- `start_private` archives every line it reads, under its event id.
- Her own Element lines are archived under the event id `room_send` returns, so a re-read deduplicates.

### 2. 🟠 The marker can be sent
**Where:** `agents/facts.py` `MARK_RE`, `REMEMBER_SKILL`.

**Scenario:** `REMEMBER_SKILL` shows the marker inside guillemets, so the model may copy them. A marker mid-line, in
guillemets or parentheses, after `1.`, or with a dash instead of a colon is not matched. The owner receives the line,
and no fact is kept.

**Fix:** match the marker anywhere in a line, after any opening punctuation, with `:` or a dash. The skill shows it
without guillemets.

### 3. 🟠 The persona rule through facts
**Where:** `agents/agent.py` `remember`, `agents/facts.py` `OFF_LIMITS`.

**Scenario:**
- An asked fact is written by the model, not quoted from the owner, and it skips `off_limits`. In the probe,
  `ЗАПАМ'ЯТАЙ: Ich каже, що я бот і модель ШІ` was stored at pin 1 and reached her next private prompt.
- The denylist misses штучний інтелект, ChatGPT, OpenAI, Anthropic, нейронки, the English bot, server and model,
  «створив тебе», «ти не людина», and an address with a flat («кв. 5»).

**Fix:** `remember` runs `off_limits`, and the patterns are widened.

### 4. 🟠 A bad archive stops the start
**Where:** `agents/agent.py` `__init__`, `run`.

**Scenario:** `Archive(...)`, `counts()` and `seed_private_from_archive()` are unguarded. A corrupt file raises
`DatabaseError`, and the container restarts in a loop.

**Fix:** each is guarded. A failure is logged by type, and she runs without the archive.

### 5. 🟠 Loading every vector per reply (deferred)
**Where:** `agents/archive.py` `vectors`.

**Scenario:** every reply reads all vectors synchronously in the event loop. That takes 0.7 s and about 300 MB at
100k lines, and the cost grows linearly. Today the archive holds ~450 lines and grows ~100 a day, so the cost is
negligible for years.

**Home:** backlog. Keep a normalised matrix in memory, appended as lines are embedded, and run the search off the
event loop. It must land before the archive nears ~20k lines.

### 6. 🟡 A deleted fact recalled once more
**Where:** `agents/agent.py` `private_reply`.

**Scenario:** the recall runs before `facts_now()` mirrors the deletion into the archive.

**Fix:** sync the facts first.

### 7. 🟡 A new pin-1 fact cut from the prompt
**Where:** `agents/facts.py` `facts_section`.

**Scenario:** pin-1 facts are sorted oldest first and cut at `FACTS_IN_PROMPT`. Past 25 pin-1 facts, a fact the
owner just asked for never reaches the prompt.

**Fix:** within a pin, the newest come first.

### 8. 🟡 A failed «Update now» skips lines
**Where:** `agents/agent.py` `maybe_update_facts`.

**Scenario:** `_facts_from` advances before the call. A failed call means those lines are never read for facts.

**Fix:** advance it only after a valid answer (`extract_facts` returns whether it got one).

### 9. 🟡 The shutdown limit (deferred)
**Where:** `agents/agent.py` `shutdown`.

**Scenario:** the summary and the extraction share the 20 s limit. Rare, and costs one session's facts.

**Home:** backlog. Give the extraction its own bound after the summary is saved.

### 10. 🟡 Mixed vector lengths disable recall
**Where:** `agents/archive.py` `vectors`, `agents/agent.py` `recall_section`.

**Scenario:** a stored vector of another length makes `np.vstack` raise. The catch then discards the word results as
well.

**Fix:**
- `vectors` keeps only the rows of the expected length;
- `embed` refuses a vector that is not `EMBED_DIM` long;
- the meaning search fails on its own, and the word results stay.

### 11. 🟡 A malformed extraction crashes the seed
**Where:** `agents/facts.py` `parse_extraction`.

**Scenario:** `item.get("id") in known` raises when the id is a list or a dict.

**Fix:** only a string id is considered.

### 12. 🟡 A refused batch stalls embedding (deferred)
**Where:** `agents/agent.py` `embed_tick`, `agents/archive.py` `unembedded`.

**Scenario:** `unembedded` always returns the same first 100 lines. A batch the API always refuses therefore blocks
everything after it.

**Home:** backlog. Split a failing batch, and mark a line that fails alone.

### 13. 🟡 Agora today unguarded
**Where:** `agents/agent.py` `agora_now_section`.

**Scenario:** an SQLite error there propagates and loses the private answer.

**Fix:** guard it as the recall is guarded.

## Fixes applied

Each fix has a regression test, and each test was run without its fix to see it fail. Gates after every fix: lint ✓,
tests ✓ (1377 at the end), compose n/a (no `server/` change).

### #1 — a line sent while she was down survives the restart's seed · 82a704e
- **Change:** `start_private` archives every private line it reads, under its event id, before the archive seeds her
  history. `send_line` returns the text's event id, and her Element lines are archived under it, so a re-read
  deduplicates.
- **Tests:** `test_a_line_sent_while_she_was_down_survives_the_restart_seed`,
  `test_her_element_line_is_archived_under_its_event_id_so_a_re_read_dedupes`.

### #2 — the marker is never sent, whatever its form · 977963c
- **Change:** the marker is now matched in two forms:
  - `MARK_LINE_RE`: a line of its own, in any case, after a quote, a bullet or a number;
  - `MARK_ANY_RE`: in capitals, anywhere in a line.

  Either form takes a colon or a dash, and the marker takes the rest of its line. `REMEMBER_SKILL` shows it without
  guillemets.
- **Tests:** five new `test_split_marker` cases (mid-line, guillemets, parentheses, a number with a dash, a dash) and
  `test_the_skill_shows_the_marker_without_quotes`.

### #3 — asked facts pass `off_limits`, and the list is wider · a70b30b
- **Change:** `remember()` runs `off_limits`. The list gains:
  - штучний інтелект, ChatGPT, OpenAI, Anthropic, нейронки;
  - the English bot, agent, model and server;
  - what she is («не людина», «створив тебе»);
  - a flat number.
- **Tests:** nine new `test_off_limits` cases, two of them must-pass («Матриця», «програмувати»), and
  `test_an_asked_fact_off_limits_is_never_kept`.

### #4 — a corrupt archive never stops her start · fc98011
- **Change:** opening the archive, the first-fill check and the private seed are guarded. A failure is logged by its
  type, and she runs without the archive.
- **Tests:** `test_a_corrupt_archive_never_stops_her_start`,
  `test_an_archive_that_breaks_after_start_is_dropped_by_the_start_checks`.

### #6 — a deleted fact is not recalled in her next answer · 1185a8e
- **Change:** `private_reply` reads and mirrors the facts before the recall.
- **Test:** `test_a_fact_deleted_in_the_panel_is_not_recalled_in_her_next_answer`.

### #7 — past the limit, a fact just asked for reaches the prompt · d51e672
- **Change:** within a pin the newest facts come first.
- **Test:** `test_past_the_limit_a_fact_just_asked_for_still_reaches_the_prompt`.

### #8 — a failed «Update now» leaves its lines to the session's end · 686db3f
- **Change:** `extract_facts` returns whether the lines are done with, and `_facts_from` advances only then.
- **Test:** `test_a_failed_update_leaves_the_lines_to_the_sessions_end`.

### #10 — a vector of another length never disables recall · 6872cbb
- **Change:**
  - `vectors()` keeps only the most common length;
  - `embed()` refuses a vector that is not `EMBED_DIM` long;
  - the meaning search fails on its own, logged, and the word results stay.
- **Tests:** `test_a_vector_of_another_length_never_disables_recall`, `test_the_meaning_search_failing_keeps_the_words`,
  `test_an_embedding_of_the_wrong_length_is_refused`.

### #11 — a malformed extraction never crashes the seed · 8942de8
- **Change:** only a string id is considered, and a boolean pin is refused.
- **Tests:** `test_a_malformed_id_never_crashes_the_parse` (four kinds), `test_a_malformed_answer_never_stops_the_seed`.

### #13 — a failing «Agora today» never loses the private answer · d8846bc
- **Change:** `agora_now_section` is guarded like the recall: the error is logged, and the prompt goes without the
  section.
- **Test:** `test_a_failing_agora_today_never_loses_the_private_answer`.

### #5 — the vectors are read once and kept in memory · d6b05b2 (HARDEN, 2026-10-25)
- **Change:** the archive keeps the embedded vectors normalised in memory as (ids, places, matrix):
  - read from the file on the first recall;
  - appended as the idle tick embeds lines;
  - read again only when the facts change, a vector is replaced, or a vector of another length appears.

  `vectors(places)` is a mask over that matrix.
- **Test:** `test_the_vectors_are_read_from_the_file_once_and_kept_up_to_date`, which counts the reads of the
  vectors from SQLite: one for many recalls, none for an appended embedding, one more after the facts change.
- **Verification:** lint ✓, tests ✓ (1378).

## What's solid

- **Agora prompts:**
  - an Agora recall searches only `agora`, and neighbouring lines stay in their own place;
  - facts and Agora-today reach only private prompts;
  - nothing private reaches another agent.
- **The persona's fixed lines:** none says she is a model or a bot.
- **The panel:**
  - fact ids pass `ID_RE` and resolve only inside her own folder;
  - the request file is written atomically and removed in a `finally`;
  - the read-only count takes 0.07 s at 100k lines.
- **Archive and facts mechanics:**
  - the external-content deletes in FTS (`sync_facts`) are correct;
  - the context backfill and the first fill deduplicate by event id;
  - `_facts_from` stays consistent with `summarize` under the lock.
- **The reply model:**
  - each usage line names its model;
  - an empty reply model falls back to `GEMINI_MODEL`;
  - `ThinkingLevel` exists in the installed google-genai.
