## v0.4 — Bot accounts and the room

### AGORA-006 — Register the ada and bruno accounts

**Description:**
Create the two bot accounts via `/_matrix/client/v3/register` with the configured `REGISTRATION_TOKEN`
(read from the host over SSH, never printed), and store the generated passwords in the Mac's gitignored
`.env` as `ADA_PASSWORD` / `BRUNO_PASSWORD`.

**What needs to be done:**
- Read the token from `~/matrix-agora/server/.env` on the host (SSH; value never echoed).
- Generate strong passwords; append `ADA_PASSWORD` / `BRUNO_PASSWORD` to the local `.env` (0600).
- Register `ada` and `bruno` with the `m.login.registration_token` flow; discard the returned access
  tokens/devices (the agents log in themselves in v0.5).

**Dependencies:** None (registration gated by the configured token since v0.3)

**Expected result:**
`@ada:agora.lan` and `@bruno:agora.lan` exist; their passwords live only in the Mac's `.env`.

**Acceptance criteria:**
- [ ] `register/available` → `M_USER_IN_USE` for both
- [ ] Passwords and the token never in argv, output, logs or commits
- [ ] **Gates:** n/a (no repo changes)
