# v5.2 — Issues

Issues for phase **v5.2 — The agents hear voice messages** (version **v5 — Voice: Hermes, the agents hear and
speak**), derived from the Tasks and DoD in [ROADMAP.md](../ROADMAP.md) §v5.2 and the contracts in
[ARCHITECTURE.md](../ARCHITECTURE.md). This file covers one phase; ids continue from the previous phase (AGORA-086 →
**AGORA-087…090**).

A voice message from the owner in Agora becomes words the room understands. **One transcript, shared by every
agent:** Hermes downloads the audio, Deepgram transcribes it, and he posts «🎙 Ich: …» as a reply to the voice event.
Every speaking agent then treats that transcript as the owner's own message: the speaker is Ich, the event id is
the transcript's, and R1, the fallback, the session, the journal and the memories apply as to a typed line. In his
private room an owner's voice message is heard the same way, and Hermes answers it in voice. The agents speaking
(v5.3) is the next phase.

**Reconciled with the code and the live setup (2026-10-18, read-only):**
- **v5.1 shipped as `v5.1.1`.** Its review moved the code:
  - the herald's guard is per sentence (`without_outing`);
  - `fetch()` reports a partial read;
  - edits are skipped (`is_edit`);
  - the private room is a conversation (`CHAT_BRIEF`, the last 20 lines, thinking `low`);
  - a stop drains a running digest.
  The code is ground truth.
- **The speakers.** `agents/agent.py` registers callbacks for `RoomMessageText` and `InviteMemberEvent` only, so an
  owner's `m.audio` today reaches no agent and is not even logged. Their `others` and their turn pools exclude the
  herald (`speakers()`).
- **Backfill.** `seed_context` keeps only `RoomMessageText`; a herald's line would be seeded under «Гермес».
- **Hermes is silent in Agora by construction.** Every send goes through `send_private`, which refuses Agora. v5.2
  adds exactly one Agora send: a transcript reply to an owner's voice event. This is the ROADMAP's design, not his
  own words.
- **nio 0.26** parses an `m.audio` event as `RoomMessageAudio` (`url`, `source.content.info.{mimetype, size,
  duration}`). Its `download()` uses the legacy unauthenticated `/_matrix/media/v3/download`. The ROADMAP asks for
  the authenticated media API (`/_matrix/client/v1/media/download/{server}/{media}` with the Bearer token), so the
  download is our own small request through `client.send`, like `join_room`.
- **Lumi's STT** (`voice/stt.py`) is a direct REST call: `POST https://api.deepgram.com/v1/listen` with `model`,
  `language` and `smart_format=true`, the header `Authorization: Token …`, the audio's content type, and a 30 s
  timeout. The transcript is at `results.channels[0].alternatives[0].transcript`.
  - Lumi's default model is `nova-3`; the ROADMAP fixes `nova-2` with `uk`.
  - `DEEPGRAM_API_KEY` is set in `~/development/lumi/.env`; `server/hermes.env` does not have it yet.
- **The usage line** (v3) has `characters` for text to speech. Deepgram bills by audio duration, so an `stt` line
  needs the audio's length.

## v5.2 — The agents hear voice messages

### AGORA-087 — The transcript rule: the `transcribe` capability, and a transcript as the owner's message for every speaker

**Description:**
Teach every speaking agent to take Hermes's transcript of an owner's voice message as the owner's own line. The
files are `agents/roster.py`, `agents/logic.py`, `agents/agent.py` and `agents/turns.py` if needed, plus the tests.

**What needs to be done:**
- **`agents/roster.py`:**
  - the herald type gains `transcribe` (`{canon, digest, transcribe}`);
  - `transcribe` is herald-only, and one member per simulation may hold it (`SINGLES`), since two transcribers
    would post twice.
- **`agents/logic.py` (pure):**
  - `TRANSCRIPT_PREFIX = "🎙 Ich: "`;
  - `transcript_content(voice_event_id, text)`: `m.text` with the body `«🎙 Ich: …»` and `m.relates_to.m.in_reply_to`
    pointing at the voice event;
  - `transcript_of(event, transcriber_id, owner_voices)`: the text when the event is a transcript, else None. A
    transcript is a `RoomMessageText` from the roster's `transcribe` member, not an edit, replying to an event in
    `owner_voices`, with the prefix; the text is what follows it.
- **`agents/agent.py`:**
  - **The audio filter:** a `RoomMessageAudio` callback. An owner's audio in `ROOM_ID` is remembered (its event
    id, in a bounded RAM set) and logged as `ignored: audio (transcribed by Hermes)`. Any other audio is logged as
    `ignored` with its reason. No agent ever answers audio itself.
  - **`on_message`:** a transcript (`transcript_of`) is handled **as the owner's message**:
    - the sender is `OWNER`, the text the transcript;
    - the event id and timestamp are the transcript's;
    - the history, the timeline, `last_owner`, the session (so the journal and the memories) all read «Ich: …»;
    - `decide` and R1, the fallback and the group address apply.
    Any other herald line stays `sender-not-allowlisted`.
  - **`seed_context` / backfill:** the same mapping, so a restart sees «Ich: …». The owner's voice ids are
    collected from the same pages.
- **ARCHITECTURE:**
  - §Message flow rule 4: the audio filter and the transcript as the owner's message;
  - §Turn-taking: R1 on a transcript;
  - §Contracts: the `transcribe` capability and the transcript format.

**Dependencies:** None

**Expected result:**
A transcript of the owner's voice is, for every speaker, exactly the owner's typed line under the transcript's event
id. An owner's audio alone, or any other herald line, never makes an agent speak.

**Acceptance criteria:**
- [ ] **Tests:**
  - `tests/test_roster.py`: `transcribe` herald-only and single;
  - `tests/test_logic.py`: `transcript_of` accepts only the transcriber's prefixed reply to a remembered owner
    voice, and refuses an edit, another sender, an unknown voice, no prefix or another room;
    `transcript_content`'s shape;
  - `tests/test_first_sync.py` or a new test: an owner's audio → `ignored`, no reply; then its transcript → R1
    chooses as for the typed words (named → that agent; unnamed → the top two; a group address → all), the
    history line is «Ich: …», the session holds it, and the fallback arms;
  - `tests/test_backfill.py`: a transcript seeds as «Ich: …», the audio not at all.
- [ ] **Contract:** the capability and the transcript rule in ARCHITECTURE §Contracts and §Message flow, pinned by
  `tests/test_logic.py`.
- [ ] **Gates:** lint, tests.

### AGORA-088 — Speech to text and the authenticated media download

**Description:**
The two building blocks Hermes needs to hear: Deepgram speech to text (`agents/voice.py`), and a capped,
authenticated media download (`agents/matrix.py`). Usage accounting goes in `agents/usage.py`.

**What needs to be done:**
- **`DeepgramSTT(api_key, model="nova-2", language="uk")`** with `async transcribe(audio, content_type) -> str |
  None`, ported from Lumi's `voice/stt.py`:
  - `POST https://api.deepgram.com/v1/listen?model=nova-2&language=uk&smart_format=true`;
  - the header `Authorization: Token …` and the audio's content type;
  - through aiohttp, with a 30 s timeout;
  - the transcript from `results.channels[0].alternatives[0].transcript`, stripped;
  - empty, a non-200 or any error → None, logged by type or status only;
  - the duration from `metadata.duration`, returned alongside for accounting.
- **`matrix.download(client, mxc, max_bytes)`:**
  - `GET /_matrix/client/v1/media/download/{server}/{media}` with the Bearer token;
  - a malformed `mxc://`, a non-200, a `Content-Length` over the cap, or a body over the cap → None;
  - the body is read at most `max_bytes + 1`.
- **`stt_usage_line(ts, agent, model, audio_ms, ok)`:**
  - kind `stt`, engine `deepgram`, billing `subscription` (Lumi's plan; never priced);
  - a new field `audio_ms`, so this is usage line v4: null on every other line;
  - `_valid` accepts it, and the report and the panel ignore it except as a row.
- **`server/hermes.env.example`** gains `DEEPGRAM_API_KEY=`.
- **ARCHITECTURE:**
  - §Voice messages: the STT and the download;
  - §Token accounting: `stt`, `audio_ms`;
  - §Contracts: the env names and the usage fields.

**Dependencies:** None

**Expected result:**
Audio bytes in, a Ukrainian transcript out, and a media file fetched with the owner's server's auth within a cap.
Every external step is mockable and silent on failure.

**Acceptance criteria:**
- [ ] **Tests:**
  - `tests/test_voice.py`, aiohttp mocked: the request's URL, query, headers and body; the transcript and the
    duration; empty, non-200 or an error → None; the key and the text never in a log;
  - `tests/test_matrix.py`, a fake `client.send`: the authenticated path and header; the cap by
    `Content-Length` and by body; a bad mxc;
  - `tests/test_usage.py`: the `stt` line's shape, and v1–v3 lines still valid;
  - `tests/test_compose.py`: the hermes env example names exactly `HERMES_PASSWORD`, `ELEVENLABS_API_KEY` and
    `DEEPGRAM_API_KEY`.
- [ ] **Contract:** the usage line v4 (`audio_ms`) and the env names in ARCHITECTURE, pinned by `tests/test_usage.py`
  and `tests/test_compose.py`.
- [ ] **Gates:** lint, tests.

### AGORA-089 — Hermes hears: transcripts into Agora, voice questions in his room answered in voice

**Description:**
Hermes transcribes the owner's voice. In Agora he posts the transcript as a reply, his one and only kind of Agora
message. In his private room he hears a voice question and answers it in voice. The files are `agents/herald.py`,
`agents/digest.py` (his readers) and `panel/static/app.js` (the `stt` kind).

**What needs to be done:**
- **The audio callback** (`RoomMessageAudio`, never in the first sync, never an edit):
  - **Agora, from the owner:** check `info.size` against `TRANSCRIBE_MAX_BYTES` (20 MB), then `download`, then
    `transcribe`, then a `stt` usage line, then `send_transcript(voice_event_id, text)`, which posts into `ROOM_ID`
    `transcript_content` and nothing else.
    - It is the only Agora send: `send_private` still refuses Agora, and a test pins that every Agora send is a
      transcript reply to an owner's voice.
    - A posted transcript counts toward the next digest.
  - **The private room, from the owner:** the same hearing. The text then goes through `route`: «підсумок» → a
    digest; anything else → the conversation.
    - Asked in voice, the chat answer goes out as voice and text (`send_voice`, the same cap and fallbacks); asked
      in text, text as before.
    - No transcript is posted in the private room.
  - Anything else (another sender, another room) is logged as `ignored`.
  - A failed or empty transcript, or audio over the cap, is logged by reason and stays silent.
- **His readers:**
  - `fetch()` maps his own transcript lines in Agora to the owner («Ich: …» in a digest and in the chat's week)
    and leaves the raw audio out;
  - `recent_dialogue` keeps the owner's voice questions as their transcripts if heard; otherwise leaves them out.
- **The key:**
  - `DEEPGRAM_API_KEY` is taken out of the environment at start like the ElevenLabs key;
  - without it he logs `hearing off` once and ignores audio.
- **The panel:** `stt` joins `KIND_ORDER`.
- **ARCHITECTURE:**
  - §The herald: hearing, the transcript post as his one Agora message, the voice answer to a voice question;
  - §Security: the Agora row changes from "never sends into Agora" to "only transcript replies to the owner's
    voice";
  - §Observability: `transcribed (N s audio, M chars)`, never a text.

**Dependencies:** AGORA-087, AGORA-088

**Expected result:**
The owner speaks in Agora and the room sees «🎙 Ich: …» within seconds; he speaks to Hermes and hears an answer.

**Acceptance criteria:**
- [ ] **Tests** (`tests/test_herald.py`; nio, Deepgram, Gemini, TTS and ffmpeg mocked):
  - an owner's Agora voice → one transcript reply into `ROOM_ID`, and the `stt` line;
  - another sender's voice or a foreign room → ignored;
  - over the cap → no download;
  - an empty or failed transcript → silence;
  - no key → hearing off;
  - every Agora send is a transcript reply to an owner voice event;
  - a private-room voice «підсумок» → a digest; a voice question → a voice + text answer; a typed question → text
    only;
  - his digest reads his transcripts as «Ich: …»;
  - no audio or transcript text in any log (the sentinel check).
- [ ] **Contract:** §The herald and §Security in ARCHITECTURE, pinned by `tests/test_herald.py`.
- [ ] **Gates:** lint, tests.
