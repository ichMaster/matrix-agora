### #1 — summary storm at the session cap
**Failure scenario:** Gemini is down or the key is revoked; the session hits 200 messages; each of the next
N messages spawns a summary call that fails → N paid/failed calls, N error lines, and the session grows
without bound for as long as the outage lasts.
**Anchor:** `agents/agent.py` `on_message` (the `SESSION_MAX_MESSAGES` early-summary trigger).
**Fix:** trigger only if the summary lock is free and `now - last_attempt_ms ≥ 60 s`; drop the oldest
entries beyond `2 × SESSION_MAX_MESSAGES`. Pin with a test (failing LLM + many messages → bounded attempts).
