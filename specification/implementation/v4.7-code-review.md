## Findings

### 1. 🟠 A model choice that cannot work
**Where:** `agents/settings.py` (the `GEMINI_MODEL` choices), `agents/llm.py`.

**Fix:** drop `gemini-2.5-pro`. The choices are `gemini-2.5-flash` and `gemini-2.5-flash-lite`, both of which can run
with no thinking.

### 2. 🟠 An hours value that validates but crashes
**Where:** `validate`, the `hours` kind.

**Fix:** validate an hours value with the agents' own `parse_hours`, so a value the agent cannot use is refused at
save time and ignored at start.

### 3. 🟠 The field shows the code default, not the server value
**Where:** `panel/static/app.js`, `settingField` and `pendingSettings`.

**Fix:**
- A field shows `override ?? the agents' common env value ?? default`, and a change is measured against that.
- A pending reset reads «reset → server value».

### 4. 🟡 The first click after typing is lost
**Fix:** a typed value only updates the Save bar in place. Only a `<select>` re-renders.

### 5. 🟡 Concurrent saves
**Fix:**
- a lock serialises `save_settings`;
- a container in state `unknown` is reported as «docker unreachable»;
- a busy restart keeps its reason.

### 6. 🟡 A failed upload
**Fix:** a short temp name, removed in `finally`. An `OSError` becomes a 400 that names the failure.

### 7. 🟡 The listing cap
**Fix:** collect, sort newest first, then slice to the cap.

### 8. 🟡 A stale Settings drawer
**Fix:**
- the poll reloads `/api/settings` while no edit is pending;
- the poll never loads a log for the settings drawer.

### 9. 🟡 A long save
Deferred. A background restart with progress would be its own feature. Every agent reads the same file at start,
so the values converge once the restarts finish.

## Fixes applied

Every fix has a regression test. After each one, lint ✓ and tests ✓; after the last, 825 tests pass, `node --check`
passes, and compose ✓.

1. **The Gemini model choices (68eb756).** Only `gemini-2.5-flash` and `gemini-2.5-flash-lite` remain; `2.5-pro` is
   refused. **Test:** `test_only_gemini_models_that_run_with_thinking_off`.
2. **Hours checked by the agents' own parser (9a0765a).** `validate` calls `parse_hours`, so `09-09`, `0-0`, `24-01`
   and `25-03` are refused. **Test:** `test_an_hours_value_the_agent_cannot_use_is_refused`.
3. **A field starts from the server value (d5abe52).** `serverValue` is the agents' common non-panel value;
   `currentValue` is the override or else that value; a reset reads «reset → server value». **Test:**
   `test_a_setting_field_starts_from_what_the_agents_run_with`.
4. **Typing updates only the Save bar (b24d25a).** `saveBarHtml` redraws the bar in place; nothing redraws on
   `change`. **Test:** `test_typing_updates_only_the_save_bar`.
5. **One save at a time (3044a2a).** A lock wraps `save_settings`, and a container in state `unknown` is reported
   «docker unreachable». **Test:** `test_saves_run_one_at_a_time_and_docker_down_is_named`, with two threads and a
   slow restart.
6. **A failed upload (af1a384).** The temp file has a short hidden name (`.upload-<hex>`) and is removed in `finally`;
   an `OSError` becomes a 400. **Test:** `test_a_failed_upload_is_a_400_and_leaves_nothing_behind`.
7. **The listing cap (5df6bab).** Files are sorted newest first, then sliced to the cap. **Test:**
   `test_the_listing_is_newest_first_over_everything_then_capped`.
8. **A stale Settings drawer (f8be3a1).** With nothing pending, the poll refreshes the view, and the drawer loads
   no log. **Test:** `test_the_open_settings_follow_the_agents_when_nothing_is_pending_and_load_no_log`.

## Architecture impact

- **`GEMINI_MODEL`:** the choices are `gemini-2.5-flash` and `gemini-2.5-flash-lite`.
- **The `hours` kind:** it is validated by `parse_hours`.
- **Settings saves:** they are serialised.
- **The panel's settings fields:** they start from the server value when nothing is overridden.

## What's solid

- **Names and values:**
  - only the schema's names pass: the file is filtered on save, and the agents check each value again at start;
  - newlines, NUL and non-finite numbers are refused;
  - a forbidden Claude name cannot be written, so `check_startup` and `scrub` still hold.
- **Precedence and reach:**
  - `settings_start` runs before every read of the environment;
  - Claude's compose interpolation is just the env layer;
  - every agent resolves the same file;
  - a save restarts only registry agents, never the panel or the homeserver.
- **The path guard:**
  - URL-encoded traversal (`%2e%2e%2f`, `..%2F`) gets a 400;
  - links and hidden names are refused anywhere on the path;
  - the upload cap holds memory to about 5 MB;
  - the download name is encoded by Starlette.
- **UI escaping:** every text — names, paths, descriptions, values, server messages — goes through `esc`.
