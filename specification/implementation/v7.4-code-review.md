## Findings

### 1. 🔴 Codex answers crash — `agents/codex_cli.py` `CodexAnswers`, `agents/responder.py` `LlmResponder.respond`

The switch wraps each client in `LlmResponder`. It calls `llm.reply` only when `complete` exists, and otherwise
`generate`. `CodexAnswers` has neither, so every Codex answer raises `AttributeError`. The owner sees «⚙️ … помилка
(AttributeError)», writing first and Agora fail, and the fallback to Gemini at the limit is never reached. The tests
called `reply()` directly.

**Fix:** `complete`, which calls `reply` as `ApiAnswers.complete` does, plus a test through `LlmResponder` and the
agent's switch.

### 2. 🔴 Codex's home is relative — `agents/agent.py` `_answer_responders`, `agents/codex_cli.py`

`cfg.memory_file` is `Path("state") / …`, so `home` is `state/kira.codex`. `clean_env` passes it as `CODEX_HOME`,
but both spawns run with `cwd` set to the work folder in `/tmp`. Codex then looks in `/tmp/…/state/kira.codex`.
`login status` fails there with words `_status` reads as `other`, which blocks the client for good under the wrong
reason.

**Fix:** resolve `home` and `work` to absolute paths. ARCHITECTURE's sign-in step names `CODEX_HOME` (the sign-in on
2026-11-12 set it by hand, so the logins are where the fixed client looks).

### 3. 🟠 An unexpected status blocks for good — `agents/codex_cli.py` `_status`, `signed_in`

Anything that is neither «ChatGPT» nor «not logged in» counts as `other` and blocks the client until a restart. That
includes a CLI error and a permissions error on `auth.json`. A `login status` that hangs is left running after its
30 s timeout.

**Fix:** block only when the words name an API key. Anything else is «not signed in» and is looked at again after
`STATUS_TTL_S`. The status process is killed and waited for in a `finally`.

### 4. 🟠 Opus's mute not restored — `agents/agent.py` `run`

v4.4 review #6 requires that a restart during a limit makes no call, and `run()` restores the mute through
`resume_status`. For a companion, `responder` is the switch and `llm` is her Gemini, so the Opus client's card is
never read back. The first Opus answer after a restart calls the CLI into the limit again.

**Fix:** also `self.opus.resume_status()` when she has one.

### 5. 🟡 A missing model named as silence — `agents/answers.py`

**Fix:** the switch sets the agent's silence reason (`LAST_SILENCE`) to «<model> недоступна (немає ключа чи входу)»,
so the ⚙️ line says why.

### 6, 7. 🟡 Counts and help — DEFER → backlog

`day_counts` counts every non-backup answer as the main model's, and Telegram's command help is set once at start.
Both are cosmetic, and `/status` names the live choice.

### 8. 🟡 The instruction file — `agents/codex_cli.py` `reply`

**Fix:** the file is written inside the `try`, and the work folder is under `$HOME` when it is set. In the companions'
containers that is `/tmp/claude`, the bounded tmpfs, like the Claude CLI's prompt files.

### 9. 🟡 A plan counted as a tool — `QUIET_ITEMS`

**Fix:** `todo_list` is quiet. A plan acts on nothing; any item that acts still drops the answer.

### 10. 🟡 httpx lines — `agents/runtime.py` `setup_logging`

**Fix:** `httpx` and `httpx2` at WARNING, as `nio` already is.

## What's solid

- **Keys:** `OPENAI_API_KEY` and `SONNET_API_KEY` leave the environment before any client exists and are handed over
  explicitly. No repr carries a key, failures are logged by type only, and usage lines carry no text.
- **Opus on Max:** it goes through `claude_client_for`, so `check_startup` and `scrub` run, every secret is removed,
  and `AuthRefused` is caught with her still running. Her photos and clips then use her own Gemini client.
- **Request shapes:** they match the installed SDKs: openai 3.49's Responses fields and refusal parts, and anthropic
  2.8's adaptive thinking, `output_config.effort` and `stop_details.category`. Cached tokens are counted once.
- **The Codex run:** its environment is a four-variable allowlist and argv carries no text. A timeout or a cancel kills
  and waits for the process, and the instruction file is removed in `finally`.
- **The switch:** it is read live, and an unknown value falls back to the default. Background kinds never reach it.
  Analytics groups by engine, so `openai` and `codex` stay apart even though both use `gpt-6.1-sol`.
