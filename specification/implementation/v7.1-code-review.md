## Findings

### 1. 🔴 The talk summaries are never written on Claude — `agents/claude_sdk.py:698`, `agents/agent.py:3713-3722`

`_talk_written` checks each summary with `probe` when the client has one (`getattr(self.llm, "probe", None) is not
None`). `ClaudeClient.probe` is a method that always returns None, which `_talk_written` reads as an outage: the
summary is thrown away, the period stays due and is tried again every 10 minutes, for good — an outage never counts
toward leaving it empty. The same method makes `_scan_open()` true, so `/scan` and the automatic scan start and stop
as failed. Invisible until an agent with `talk` moves (Кіра, v7.3), but the summaries are among v7.1's calls.
**Fix:** `probe = None` on `ClaudeClient` (the callers skip the check and keep the text; the scan is off, as v7.3
intends); a talk-writer test on `ClaudeClient`.

### 2. 🟠 Answers queue behind background calls — `agents/claude_sdk.py` `_query`

One semaphore (`CLAUDE_CONCURRENCY`, 2) is held across both tries of a call. Two background calls (facts, topics, the
today block, a talk summary) can hold it up to 2 × `THINK_TIMEOUT_S` each; an Agora reply or a private answer waits
that long before its own timeout starts, and the turn-taking then drops it («moved on», past `FALLBACK_S`).
**Fix:** the voice's calls (`VOICE_KINDS`) get a gate of their own, so an answer never waits behind the background.

### 3. 🟠 Overage is not muted — `agents/claude_sdk.py` `_judge` and `ClaudeSdkResponder`

A `RateLimitEvent` with status `allowed` and `raw.isUsingOverage` clears `muted_until`; the answer is dropped (no
extra usage, ever) and the call goes to Gemini, but the next call goes to Claude again, is billed as overage again
and dropped again — on every call while it lasts. Claude himself (v4.4) has the same gap.
**Fix:** on an over-limit answer, mute until the window's reset (`resets_at`) or `WARN_MUTE_S`, in both.

### 4. 🟡 The first blocked call is lost — `agents/claude_sdk.py` `_judge`

When the init's check blocks the client (`apiKeySource` not `none`), that call returns None; only the later calls
take the fallback. **Fix:** return `_LIMIT` for a call that found the client blocked, so `_run` takes decision 1.

### 5. 🟡 Hermes's refusal unhandled — `agents/agent.py` `main`

Only `Agent(cfg)` is wrapped in `except AuthRefused`; `Herald(cfg)` raises a traceback and writes no `refused:` card.
**Fix:** the same wrap for both.

### 6. 🟡 The fallback's answers counted as Claude's — `agents/agent.py` `reply` (`record_answer`)

`record_answer` writes `claude` whenever the engine is `claude-sdk`, so the §v7 «How much slower» comparison counts
Gemini's fallback answers as Claude's. **Fix:** the client says who served the call (a context variable, as
`LAST_BLOCK`), and the answer line uses it.

### 7. 🟡 A partial prompt file left behind — `agents/claude_sdk.py` `_prompt_file`

If `os.write` fails (the 64 MB tmpfs full), the file exists but its path is never returned, so it is never removed;
a short write is not checked. **Fix:** write it whole in a loop and remove it on any error.

### 8. 🟡 A missing SDK raises out of the calls — `agents/claude_sdk.py` `_query`

`_default_query()` / `_default_options()` run outside the `try`: on a service started from the wrong image every
call raises `ImportError`. **Fix:** inside the `try`, logged as a failed call.

### 9. 🟡 The panel's Gemini settings and the fallback — DEFER → v7.2

`GEMINI_MODEL`, `GEMINI_REPLY_MODEL`, `GEMINI_THINKING_LEVEL` are scoped `engine:gemini`; on an agent on Claude its
Gemini fallback reads them from the env files only, and the panel's overrides are ignored. v7.2 moves the room and
decides how the fallback's settings show.

### 10. 🟡 The photos' Gemini key — DEFER → v7.3

`claude_client_for` pops `GEMINI_API_KEY` before `photo_maker` and `clip_maker`, which build `genai.Client()` from
the environment; v7.3 brings Кіра's photos on Claude and has to hand them the key.

## What's solid

- No path returns text from an unchecked call: `_judge` builds text only after the init, not blocked, not over the
  limit, not refused.
- No secret or text in argv or a log: the system prompt by a 0600 file in a 0700 folder, removed after the call; the
  user prompt over stdin.
- The fallback's shapes match `GeminiClient`'s (`(text, finish)` from `complete` / `reply`, a string from
  `generate` / `think` / `search`), and `think` never sends a Claude alias to Gemini; `LAST_BLOCK` as on Gemini.
- Secrets popped after the agent's own password is read; the Gemini key handed to the Gemini client alone.
- The headroom math, cap 0 included; the usage line's `blocked`; the settings scopes, the panel views, `deploy.sh`,
  `run-agent.sh` and the compose checks.
