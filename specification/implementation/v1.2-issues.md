## v1.2 — Three-way conversation and loop protection

### AGORA-014 — Turn-taking: mentions, bot_streak, delays, PASS — pure + wired

**Description:**
The pure who-replies decision per ARCHITECTURE §Turn-taking, wired with injectable randomness and
non-blocking scheduled replies.

**What needs to be done:**
- Mention detection (pure): the agent's name in any Ukrainian case form (Ада/Ади/Аді/Аду/Адо…,
  Бруно — invariant) or a Matrix mention of its user id; case-insensitive.
- `decide_reply(sender, text, streak, cfg, rng) -> ReplyDecision{reply: bool, delay_s: float}` (pure):
  - owner + my mention → reply, no delay; owner + other's mention only → silent;
  - owner + no mention → reply after `uniform(1, REPLY_DELAY_S)`;
  - other agent → reply only if `streak < MAX_BOT_TURNS` and `rng() < BOT_REPLY_P`, with the same delay;
  - anything else → silent.
- `bot_streak` (pure): computed from the history tail — consecutive agent messages since the owner's last;
  derived identically by both agents from the shared timeline; reset by an owner message.
- `PASS`: strip the reply; exactly `PASS` (whitespace/punctuation-tolerant) → send nothing; the instruction
  gains the literal permission line «Якщо тобі нема чого додати — відповідай рівно PASS.»
- Wiring: replies run as scheduled tasks (`asyncio.create_task` + sleep(delay)) so the sync loop never
  blocks (fixes v1.1 review #3); re-check the latest history at fire time (a newer owner message replaces
  stale context naturally via the shared buffer).
- Settings: `MAX_BOT_TURNS` (2), `BOT_REPLY_P` (0.5), `REPLY_DELAY_S` (4) from `.env` with defaults;
  `.env.example` updated.

**Dependencies:** None

**Expected result:**
Both agents converse with the owner and each other, bounded by the streak and probability gates.

**Acceptance criteria:**
- [ ] **Tests:** mention detection incl. the vocative «Адо» and Matrix ids; the full who-replies table
      (owner±mention, other agent under/over streak, probability edges with injected rng); `bot_streak`
      from message sequences incl. reset; `PASS` with whitespace; delay bounds — all pure, rng injected
- [ ] **Contract:** turn-taking semantics land as specified (no doc change)
- [ ] **Gates:** lint ✓ tests ✓
