## Findings

### 1. 🔴 Glob/Grep escape the folder
**Where:** `_inside`, `tool_denial` ([agents/claude_sdk.py](../../agents/claude_sdk.py)).

**How the escape works:**
- `os.path.isabs(" /app/state")` is false, so the guard joins the path under `/workspace` and allows it.
- The CLI's `expandPath` then trims it and expands `~`, so it searches `/app/state`, the whole `state/` mount: every agent's Matrix token, memories and plans with their hidden mutation tags.
- `/app/agents` is open the same way: the persona canons and life stories, future chapters and death date included.
- A Glob pattern such as `{/app/state,x}/*` escapes through a brace alternative.
- A fetched page could steer this (prompt injection) and send what it finds out through WebFetch.

**Fix:**
- Refuse any path with surrounding whitespace, a leading `~` or a `$`.
- Compare `realpath` against the workspace's `realpath`.
- Refuse a Glob pattern or Grep `glob` with an absolute or `~` alternative, or `..`.
- The hook denies on any exception (fail closed).

### 2. 🔴 A named exchange never ends
**Where:** `decide_reply` ([agents/turns.py](../../agents/turns.py)); `resume_later` ([agents/agent.py](../../agents/agent.py)).

**The loop:** «Бруно, …» → Bruno answers «Адо, …» → Ada answers. At the wave limit, R4 parks the candidate. When the window frees, `decide()` runs again and the candidate is still named, so no coin is tossed. The design draft predicted this (more-agents.md: "the agents name each other constantly").

**Fix:**
- An address is always answered inside a live burst. A **resumed** decision (R4) always tosses the coin, so an exchange still ends after a few bursts.
- `decide_reply(..., resumed=True)` from `resume_later`.
- A test drives a named ping-pong across R4.

### 3. 🟠 The named cat and R2 both answer
**Where:** `next_speaker` ([agents/turns.py](../../agents/turns.py)).

**The clash:** the cat's name forms are ordinary words (кіт, кота…). Since ba0b384, a message that names him makes him speak every time; before, about 12% of the time. That message names no ranked member, so R2 also picks an unnamed candidate. Whoever lands second fails R3. That is usually Claude, whose reply takes long, so his quota is spent for nothing.

**Fix:** R2 returns no candidate when the message names an ambient member and no ranked or mention-only one. Every agent computes this from the same inputs.

### 4. 🟠 An owner question lost in a slow reply
**Where:** `on_message` coalescing, `reply_later` ([agents/agent.py](../../agents/agent.py)).

**The loss:** Claude is writing a philosopher answer to an unnamed owner message (20–180 s). The owner writes «Клоде, так чи ні?». That message coalesces into the pending reply, whose trigger stays `None`. The old reply is sent, `reply_later` sees it as sent and ends. The named question is never answered.

**Fix:**
- Count the owner messages that coalesce into a pending reply.
- If one arrived after a pass began reading the context, run one more pass.

### 5. 🟠 A group address is not «unasked»
**Where:** `claude_mode` ([agents/turns.py](../../agents/turns.py)).

**Fix:** `direct` also when `addresses_everyone(answered_text)`, as in v4.4; a test case.

### 6. 🟠 The news never fires
**Where:** `maybe_news` ([agents/agent.py](../../agents/agent.py)); the live `CAT_NUDGE_IDLE_S=1200`.

**Why:** the news waits for 60 minutes of room silence, counted from the last message of anyone, the cat's nudges included. With the cat at 20 minutes, that silence never comes.

**Fix:** the owner's decision on how often the news should come. Then make the news's wait independent of the cat's, while it still never interrupts a live talk.

## What's solid
- **Turn-taking stays deterministic.** The coin only decides *whether* the single candidate speaks. `next_speaker`, `rank` and `ambient_draw` depend only on the event id and the roster, and no shared state was added.
- **Owner reservations are unchanged.** Dropping `from_owner` from `ambient_draw` keeps the owner path the same, so `owner_speakers` and `pending_answers` reserve the same answers.
- **Tool names are an exact allowlist.** Case variants, MultiEdit, NotebookEdit, Bash and MCP tools are refused. The hook's matcher covers every tool. Read, Write and Edit get a normalized absolute path from the CLI.
- **The init check fails closed.** The tools must be a subset of the allowed set, `apiKeySource` must be `none`, and there must be no MCP servers. Live it reports `auth: oauth`.
- **The news guards and their state.**
  - Each attempt is recorded before the call. The state file is atomic and 0600, with no texts.
  - Before sending, it checks the room is still quiet.
  - The roster allows at most one member per initiative.
- **The panel's news line.**
  - The path is built from the registry name only.
  - Bad files never cause a 500.
  - The text is escaped.
- **Backfill paging.** At most 5 pages. It stops on an empty page or a repeated token, and a failed page keeps what it already has.
