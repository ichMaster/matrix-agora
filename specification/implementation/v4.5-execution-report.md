### AGORA-065: The philosopher mode
**Status:** completed · **Commits:** dbd2c04, c076819, 8856ff2 · **GitHub:** #65
**Gates:** [x] lint · [x] tests · [x] compose
- **`claude_mode(answered_text, name_forms, user_id)`** (`agents/turns.py`, pure): `direct` when the message he answers names him (any name form, Latin «Claude», his Matrix id), `philosopher` otherwise. The answered message is the owner's for an answer to the owner and the trigger's for an agent-to-agent reply.
- **Direct mode:** `CLAUDE_BRIEF_DIRECT` over the last `HISTORY_N` lines.
- **Philosopher mode:** `CLAUDE_BRIEF_PHILOSOPHER` over a RAM window of the last `CLAUDE_HISTORY_N` (150) room messages, seeded from the room and never written, with `effort="high"`.
- **The owner's changes during the phase (c076819):** adaptive thinking in both modes; the philosopher speaks in 1–3 sentences instead of the designed 2–4.
- **The live fix (8856ff2):** the homeserver caps a `/messages` page at 100 events, so the 150-message window was seeded with only 100 after a restart. The backfill now pages back up to 5 pages; the live log shows «seeded with 150».

### AGORA-068: Claude's tools
**Status:** completed · **Commit:** 744f695 · **GitHub:** #68
**Gates:** [x] lint · [x] tests · [x] compose
- **Tools allowed:** Read, Write, Edit, Glob and Grep, confined to his own folder `/workspace` (compose: `../claude-workspace`, created by `server/deploy.sh`), plus WebSearch and WebFetch to public hosts only.
- **Tools refused:** Bash, Agent, Skill, NotebookEdit and the rest are disallowed. A PreToolUse hook (`tool_guard` → the pure `tool_denial`) denies any other tool, any path outside the folder and any private, loopback or LAN host.

- **The init check:** it now accepts any tool list within the allowed set, and still requires no API key and no MCP servers.
