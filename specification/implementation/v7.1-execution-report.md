## The owner's changes during the phase (2026-11-10)

- **Thinking** (`CLAUDE_THINKING`, `CLAUDE_EFFORT`; «а Сонет має мислення?» → «додай»): commit 0faf36b. The room's
  six answer without it (v7.2), Hermes, Кіра and Устина `adaptive` at `low` when they move.
- **An error result read, not lost** (e607de5, ddeb710): the CLI reports a refusal or a 429 as an error result and
  exits 1, which the SDK raises as `ResultError` after it; `ClaudeClient` and Claude's own responder now read that
  result (a decline is a decline with the classifier's category in the log, a 429 mutes), and an error result's log
  line names its stop, terminal reason and the kind of CLI error. Found when a made-up benchmark prompt (a word
  salad) tripped Haiku 5.5's `bio` safety classifier.
- **No thinking on Haiku, more tokens** (b28885d; «для хайку не треба думання», «тоді збільш кількість токенів»):
  a 5.5 model thinks whatever the CLI is told — Haiku 5.5 thought 600–1,300 tokens with `--thinking disabled`,
  `--max-thinking-tokens 0` or `MAX_THINKING_TOKENS=0`, and 150–300 at `--effort low`. Every call that does not think
  now runs at `low`, every capped call gets 4096 tokens on top, and an answer with no tools is joined from all its
  text blocks — the thinking had eaten the cap and the CLI's continuation left only the last part in the result.

## Speed, before any agent moves (the owner: «поміряй швидкість в порівнянні до джемені моделей раніше»)

Measured 2026-11-10 from the Mac, one call at a time, through the real clients (`GeminiClient` as the agents call
Gemini today, `ClaudeClient` of b28885d with the CLI started for every call), on made-up everyday Ukrainian prompts
of the sizes of each kind's real calls (the panel's Analytics, 2026-11-03..09, mean prompt tokens); every prompt
unique, so no cache helps either side. Gemini's calls cost about $0.6; Claude's ~40 calls came off the subscription.
The server's column is the agents' real week on Gemini (Analytics · Speed, median / p95 of `latency_ms`).

| Call (size in Gemini tokens) | Gemini, the server's week | Gemini, same prompt | Claude, same prompt |
|---|---|---|---|
| Room answer (~24k) | Flash 1.3–1.8 s / 2.0–2.4 s | Flash 1.0 / 1.2 s | Haiku 2.8 / 3.7 s |
| The cat's answer (~17k) | Flash 1.3 / 2.1 s | Flash 1.1 / 1.8 s | Haiku 2.4 / 2.4 s |
| Session summary (~2.5k) | Flash 2.9 / 3.4 s | Flash 2.6 / 4.1 s | Haiku 3.9 / 4.3 s |
| Today block (~5k) | Flash 1.6–2.0 / 2.0–5.6 s | Flash 2.3 / 2.7 s | Haiku 5.1 / 5.2 s |
| Кіра's topics (~1.3k) | Flash 1.4 / 1.8 s | Flash 1.6 / 2.6 s | Haiku 3.6 / 3.8 s |
| Кіра's talk summary (~5k) | 3.1 Pro 13.3 / 20.2 s | 3.1 Pro 14.5 / 15.0 s | Haiku 4.9 / 5.5 s |
| Hermes's digest (~2k) | 3.1 Pro 22.0 / 33.2 s | 3.1 Pro 20.8 / 22.2 s | Sonnet, adaptive low, 14.5 / 15.0 s |
| Кіра's private answer (~29k) | 3.1 Pro 13.5 / 23.4 s | 3.1 Pro 9.3 / 12.0 s | Sonnet 5.4 / 6.1 s; adaptive low 5.2 / 6.7 s |

What it says: on Haiku the room's answers and background calls are slower than on Flash by about 1.5–3 s a call —
the CLI's start is part of every call; on Sonnet Кіра's and Устина's answers are about twice as fast as on 3.1 Pro,
and the talk summaries (Pro → Haiku) three times as fast; Hermes's digest about a third faster. At `low` Sonnet chose
not to think on these answers (0 thinking tokens), so `adaptive` cost no time there. Not measured: the server's
network, calls at once, the prompt cache on a stable canon (it can only help Claude), a real day's load on the
subscription — those are v7.2's day of the room.

The two are alike on Claude: Кіра's larger prompts (~30k against ~19k tokens) cost Sonnet under half a second.
Sonnet is the fastest for their answers — about twice 3.1 Pro's speed, writing first more than twice; Opus is

came out cut (12–16 characters: the thinking ate the cap), so the server's week is its measure. On Haiku the
background calls that run on Flash today are 2–7 s slower — the facts most, where Haiku thinks ~1,000 tokens even
at `low`; the talk summaries, on 3.1 Pro today, three times faster. Speed only: the prompts are made up, so what
