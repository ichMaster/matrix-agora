### AGORA-010 — agent.py: session, invites, first-sync, filter, echo — with unit tests

**Description:**
`agents/agent.py`: the nio client wiring plus the pure decision functions, per ARCHITECTURE §Message flow.
Echo reply `"<name> чує: <text>"`.

**What needs to be done:**
- **Session:** first run — password login, save `access_token`+`device_id` to `state/<name>.json` (0600,
  atomic write); later runs — restore; corrupt/missing file → password login fallback, logged.
- **Invites:** join only `OWNER`'s invites into `ROOM_ID`; others leave/ignore (logged `ignored`).
- **Startup:** first `sync` only for `next_batch` (events unprocessed), then `sync_forever`.
- **Pure filter:** `should_handle(room_id, sender, cfg) -> bool | reason` — only `ROOM_ID`, not self,
  sender ∈ {OWNER, the other agent}; everything else `ignored` with the reason.
- **Echo:** reply `"<name> чує: <text>"` as `m.text`; only `RoomMessageText` events handled.
- **Robustness:** a callback exception must not kill `sync_forever`; no tokens/texts in logs.

**Dependencies:** AGORA-009

**Expected result:**
`uv run agents/agent.py agents/ada.toml` runs against the live server; logic is unit-tested without nio.

**Acceptance criteria:**
- [ ] **Tests:** filter table (own message / foreign sender / foreign room / DM / owner / other agent),
      session save/restore round-trip + corrupt file, first-sync skip decision, echo formatting — nio mocked,
      no network
- [ ] **Contract:** the `state/<name>.json` shape and the filter rule land as specified (ARCHITECTURE
      §Contracts — new, no doc change)
- [ ] **Gates:** lint ✓ tests ✓
- [ ] No secrets or message texts in logs
