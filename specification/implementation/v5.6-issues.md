# v5.6 — Issues

Issues for phase **v5.6 — A private chat with a person (Кіра first)** (version **v5 — Voice: Hermes, the agents
hear and speak**), derived from the Tasks and DoD in [ROADMAP.md](../ROADMAP.md) §v5.6 and the contracts in
[ARCHITECTURE.md](../ARCHITECTURE.md). This file covers one phase; ids continue from the previous phase
(AGORA-102 → **AGORA-103…105**).

A person with the new `private` capability accepts the owner's invite into one private chat beside Agora. There
she answers every message in her voice and now and then writes first. What she hears there joins her one memory,
and in Agora she keeps it to herself. Only Кіра has the capability for now.

**Reconciled with the code (2026-10-20, read-only):**
- **The filters.** `should_handle` (`agents/logic.py`) handles only `ROOM_ID`; `should_join_invite` joins only the
  owner's invite into `ROOM_ID`. Every other room and invite is `ignored` and left (`on_invite`,
  `join_pending_invites` in `agents/agent.py`).
- **The reply path:** `on_message` → `decide` (turn-taking) → `reply_later` → `reply` → `_compose(prompt, lines)` →
  `send_line` (voice under `voice_due`, the speakers' budget, then the text).
  - `_compose` takes the history (`lines`), so a private history can stand in for Agora's.
  - `reply` runs the R3 re-check and the fallback check; a private answer needs neither.
- **The memory.** `on_message` appends Agora lines to `self.session` → `summarize` → `memory.md` and the day's
  journal (`append_journal`, `<name>.days/<date>.talk.md`) → day memories, digests and plans. A private line
  appended to the session, labelled, reaches all of them.
- **Prompt assembly.** `build_instruction` has a fixed order (ARCHITECTURE §Prompt assembly) and `rules_extra` for
  the creature. A private brief and a discretion line are new sections.
- **The initiative.** `nudge_due` (`agents/nudge.py`) is generic: idle, hours, per day, gap. It is reused here.
  `idle_watcher` already runs the cat's nudge and Claude's news.
- **Capabilities.** `CAPABILITIES` in `agents/roster.py`; a TOML's `[capabilities]` table overrides the type's
  defaults, so a capability that no type holds by default can be switched on per person.
- **What the private chat doesn't reach.** The owner's voice messages reach the room only through Hermes's
  transcripts (v5.2), and Hermes is not in the private chat. So a voice message there isn't heard; this phase
  leaves it `ignored`.

## v5.6 — A private chat with a person (Кіра first)

### AGORA-103 — The private chat's rules: the capability, the invite and filter rules, the prompt sections, the settings and state

**Description:**
The pure decisions behind a private chat, in `agents/logic.py`, `agents/roster.py`, `agents/settings.py` and a small
`agents/private.py`. The contracts change: the filter and invite rules, the `state/` file, and the prompt order.

**What needs to be done:**
- **The capability `private`** in `CAPABILITIES`. No type holds it by default; a person's TOML enables it.
- **The invite rule** `should_join_invite(room_id, inviter, cfg, private_room)`:
  - Agora as before;
  - otherwise yes only when the agent `can("private")`, the inviter is the owner, the room isn't Agora, and there
    is no private room yet or it is the same one. One private room per agent.
- **The filter** `should_handle(room_id, sender, cfg, others, private_room)`:
  - Agora as before;
  - the private room only from the owner, as `Verdict(True, "private")`;
  - in the private room, any other sender is `sender-not-allowlisted`;
  - every other room stays `foreign-room`.
- **The prompt sections** in `build_instruction`:
  - **`PRIVATE_BRIEF`** (a private reply). «Зараз ви з Ich удвох, в окремій розмові, не в Агорі», warm and
    personal, her own words. What is said here stays between them.
  - **`PRIVATE_DISCRETION`** (her Agora replies, only with `private`). What was said privately with Ich stays
    private: never retold, never hinted at.
  - **`PRIVATE_NUDGE`.** Ich hasn't written for a while. One short line of her own, from her day, today or
    plans, as to someone close. Never asking why he is silent.
  - All three stay persona-safe (`BANNED_RE`) and go into the documented order.
- **The settings** (agent settings, `cap:private`):
  - `PRIVATE_IDLE_S` (21600 — six hours of private silence);
  - `PRIVATE_NUDGES_PER_DAY` (2);
  - `PRIVATE_HOURS` (`10-22`).
- **The state** `state/<name>.private.json` (`agents/private.py`):
  - `room`;
  - the initiative's `last_ms`, `day` and `count`.

  Atomic and 0600, with no texts. A corrupt file starts fresh, and the room is rediscovered at start (AGORA-104).
- **The initiative's decision:** `nudge_due` with the private settings and the private chat's last message.
- **ARCHITECTURE:**
  - §Message flow and §Contracts: the filter and invite rules;
  - §Data and state files: the new file;
  - §Configuration: the settings;
  - §Prompt assembly: the private brief and the discretion line;
  - the capability list.

  **VISION:** a person may have a private chat with the owner.

**Dependencies:** None

**Expected result:**
Every private-chat decision is a pure function, pinned by tests, before any runtime uses it.

**Acceptance criteria:**
- [ ] **Tests:**
  - the invite rule: the owner into a new room with `private` → yes; a stranger, without `private`, a second room
    → no; Agora unchanged;
  - the filter table with the private room: the owner → handled, another member or a stranger → ignored, other
    rooms → ignored;
  - the prompt order with the private brief or the discretion line, and no banned word;
  - the settings in the schema (defaults, bounds, `cap:private` concerns only Кіра once enabled);
  - the state round-trip, corrupt → fresh, 0600;
  - `nudge_due` with the private values (idle, hours, the day's count, the gap).
- [ ] **Contract:** the filter and invite rules, the `state/` file and the prompt order are updated in
  ARCHITECTURE and pinned by `tests/test_logic.py` and the new `tests/test_private.py`.
- [ ] **Gates:** lint, tests.

### AGORA-104 — Кіра in her private chat: joining, answering in voice, one memory, writing first

**Description:**
The runtime in `agents/agent.py`, plus `agents/kira.toml` enabling the capability. The agent joins the owner's
invite and answers there outside Agora's turn-taking, in voice. Its private lines feed the one memory, and after a
long silence it writes first.

**What needs to be done:**
- **Joining:**
  - `on_invite` and `join_pending_invites` use the new invite rule; joining a private room saves it in the state;
  - at start, without a stored room, the private room is rediscovered: a joined room other than Agora whose
    members are the agent and the owner only.
- **Answering:**
  - in the private room every owner message is answered, with no `decide`, no wave and no roll;
  - after a short typing delay (1–`REPLY_DELAY_S`): typing on → `ensure_today` → the persona prompt with
    `PRIVATE_BRIEF` → `_compose(lines=private history)` → `send_line(private room, …)` → typing off in a `finally`;
  - a message that arrives while an answer is on its way coalesces into it, and gets one more pass if it came
    during generation;
  - the private history is the room's last `HISTORY_N` lines, its own and the owner's, seeded from the room at
    start like Agora's backfill. It is never Agora's history.
- **One memory:**
  - the private lines go into `self.session`, labelled («Ich (наодинці)», «Кіра (наодинці)»), so the summary, the
    day's journal, the day memory and the plans know them;
  - her Agora prompt carries `PRIVATE_DISCRETION`.
- **Writing first:**
  - `idle_watcher` runs `maybe_private_nudge` with `nudge_due` and the private settings, never while a private
    answer is on its way;
  - the state counts sent lines; a restart never writes at once.
- **Accounting:** the usage kinds `private` and `private_nudge`. Logs carry counts and reasons, never a word.
- **Ignored:** any other sender or a voice message in the private room is logged `ignored`. Agora's turn-taking,
  Hermes and the recording never see the private room.
- **`agents/kira.toml`:** `[capabilities] private = true`.

**Dependencies:** AGORA-103

**Expected result:**
Кіра joins the owner's private chat and talks there in her voice, as the one Кіра who remembers.

**Acceptance criteria:**
- [ ] **Tests** (nio and the model mocked; the clock injected):
  - the invite: joined and stored, rediscovered at start, a second room refused;
  - an owner message in the private room → one answer in the private room with the private brief and history,
    and none in Agora;
  - a stranger in the private room → ignored;
  - coalescing;
  - the session gets labelled private lines; the Agora prompt carries the discretion line, the private prompt
    doesn't;
  - `maybe_private_nudge`: due, hours, the day's cap, not while answering, the state saved;
  - the usage kinds;
  - no text in logs;
  - only Кіра has `private`.
- [ ] **Gates:** lint, tests.
