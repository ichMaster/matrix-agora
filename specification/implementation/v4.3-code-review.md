## Findings

### 1. 🟠 A purr releases the cat's reservation early
**Where:** `pending_answers` ([agents/turns.py](../../agents/turns.py)), `purr_later` ([agents/agent.py](../../agents/agent.py)).

**Scenario:** «Адо, Бруно і коте, як ви?» reserves all three. Ada answers; the cat, whose spoken answer is still generating, purrs at Ada's line (purrs skip `_reply_pending`); since #13 any line counts as arriving, so his reservation is released; Bruno answers; Ada's R2 on Bruno's line sees wave 2 + reserved 0 and replies; then the cat's spoken line lands — 4 agent lines against `MAX_BOT_TURNS=3` (reproduced through `Agent.decide`). `simulate()` never schedules a purr for an agent with a pending entry, so the suite stayed green.

**Fix:** `purr_later` drops the purr when a reply of his own is on its way (`_reply_pending`) — his own state only. Regression test at the agent.

### 2. 🟠 A nudge worded as a purr
**Where:** `nudge` ([agents/agent.py](../../agents/agent.py)).

**Scenario:** CREATURE_RULES ask for few words; the model may answer «Мрр… *позіхає*». It is sent, counted, `sent_ms` and `told` set — and every agent marks it a purr, so nobody answers: a paid call, one of six nudges, and the DoD's "someone answers him" missed. ARCHITECTURE says a nudge is never a purr.

**Fix:** a purr-worded nudge is silent (`nudge silent: purr`) — an attempt, not a nudge. Regression test.

### 3. 🟠 Tags match inside common words
**Where:** `pick_memory` ([agents/pastlife.py](../../agents/pastlife.py)), [agents/canon/kit.memories.md](../../agents/canon/kit.memories.md).

**Scenario:** substring matching lets «баг» fire on «багато», «кава» on «цікава», «чат» on «почати», «права» on «справа», «спек» on «перспектива», «суд» on «посуд», «дах» on «сходах», «зорі» on «прозорі», «логи» on «діалоги», `ping` on "typing", `top` on "desktop", `irc` on "circle"; and a few tags are whole common words or their starts («відповід», «побачення» in «до побачення», «місц» in «місце», «гул» in «гуляти», «секунд» in «секунду»). The nudge joins the last five messages, so nearly every memory nudge hits a false tag.

**Fix:** tags match only at a word start (`(?<!\w)tag`); the tags that still start common words are replaced. Regression test: a list of everyday words and phrases triggers no tag of the real file.

### 4. 🟠 A thesis leads to his hidden end
**Where:** [agents/canon/kit.memories.md](../../agents/canon/kit.memories.md) («Годинник у кутку екрана рахував секунди з 1970-го … Я так і не спитав, до скількох»), [tests/test_pastlife.py](../../tests/test_pastlife.py).

**Scenario:** his death is the 32-bit `time_t` overflow (2038-01-19 03:14:07 UTC); the hidden chapter dreams of «число, яке не вміщається в тридцять два біти». This thesis asks exactly that, and Gemini may answer it in the room («до 2³¹ — січень 2038-го») — into Ada's and Bruno's day memories for good. The content test only bans "2038".

**Fix:** the thesis keeps the clock and drops the question of where it ends; the content test also bans `2147483647`, «32 біт», «тридцять два біт», "2^31", «2³¹» and «до скількох».

The state file is listed without `sent_ms`. ARCHITECTURE says the memory view's `pastlife`/`nudge` are pinned by `test_panel_api.py`; they are pinned by `test_panel_memory.py`.

### 6. 🟡 "The only initiator" is not enforced
**Where:** `parse_member`, `load_roster` ([agents/roster.py](../../agents/roster.py)).

**Scenario:** `[capabilities] nudge = true` on a persona loads, and Ada would post Linux lines after every silence; a second creature would be a second initiator racing the first on the same silence.

**Fix:** `pastlife` and `nudge` belong to the `creature` type only (a named error otherwise), and a simulation may hold at most one member with `nudge`. Pinned by `tests/test_roster.py`; ARCHITECTURE §Contracts records it.

### 7. 🟡 Cat-only settings take the room down
**Where:** `Agent.__init__` ([agents/agent.py](../../agents/agent.py)).

**Scenario:** every agent parses `CAT_NUDGE_HOURS` at startup and they share `env_file`, so `22-09` or `09:00-22:00` crash-loops Ada, Bruno and Кіт. And a `CAT_NUDGE_IDLE_S` below `BOT_WINDOW_S` (600) lets a nudge land as the 4th line of a live wave, where R2 blocks every answer.

**Fix:** only an agent with `nudge` reads the nudge settings; its silence is at least `BOT_WINDOW_S` (logged when raised). Regression tests.

### 8. 🟡 The no-repeat rule switches off after one cycle
**Where:** `_pick_thesis`, `nudge` ([agents/agent.py](../../agents/agent.py)).

**Scenario:** when all theses are told, `pick_memory` treats all as candidates but `told` stays full, so from then on a thesis can repeat back to back (AGORA-055: "starts over").

**Fix:** `told` is cleared once every thesis is told. Regression test.

### 9. 🟡 An empty timeline after a restart
**Where:** `maybe_nudge` ([agents/agent.py](../../agents/agent.py)).

**Scenario:** if the startup backfill fails, the timeline is empty, the room counts as quiet, and he nudges at the first tick with an empty transcript — ignoring talk from just before the restart.

**Fix:** the silence counts from the later of the last room message and the agent's start. Regression test.

### 10. 🟡 The last nudge without a date
**Where:** `pastLifeLine` ([panel/static/app.js](../../panel/static/app.js)).

**Fix:** a nudge from another day shows a short date («last nudge Oct 7, 21:40»). Static test.

### 11. 🟡 Tests that pin the wrong thing
**Where:** [tests/test_pastlife.py](../../tests/test_pastlife.py), [tests/test_roster.py](../../tests/test_roster.py), [tests/test_panel_memory.py](../../tests/test_panel_memory.py), [tests/test_compose.py](../../tests/test_compose.py).

**Fix:** the theses count is 60–100 and the panel's count equals the parsed file's; a test compares the `CAT_*` values in `.env.example` with the agent's defaults.

### 12. 🟡 «ім'ям мого кота»
**Where:** [agents/canon/kit.memories.md](../../agents/canon/kit.memories.md).

**Fix:** «ім'ям кота сусідки» — the cat of his childhood, as in the life story.

### 13. 🟡 Consecutive unanswered nudges — DEFER → backlog
The design allows a nudge every `CAT_NUDGE_IDLE_S` up to the cap; with `BOT_REPLY_P` 0.5 about half go unanswered, and a quiet morning can spend all six. Holding back while the last line is his own would change the owner's design; raised for the owner.

### 14. 🟡 A failed send counts — DEFER → backlog
`room_send`'s result is not checked in `nudge()` (nor in `reply()`, pre-existing): a `RoomSendError` still counts the nudge. One fix for both paths belongs to a later hardening pass.

### 15. 🟡 A hand-fed wave in the fresh-wave test — DEFER → cleanup
The test passes `wave=1`; computing it through `Agent.decide` and `reserved()` would pin more.

## What's solid

- **No paid loop:** `maybe_nudge` records the attempt before any model call; a failed state write raises before the call; silent attempts are spaced by the idle time.
- **The pre-send quiet check holds:** the marker is taken with the due check, and any reply that races a nudge adds a timeline entry first.
- **The `_compose` refactor changed nothing** in the reply's order (trim, `clean_reply`, PASS, word cap, duplicate, guard, R3, fallback, send); typing resets in `finally` on both paths.
- **Secrets and the human-belief rule:** no texts in logs or the state file (atomic, 0600); the past-life and nudge sections are gated by capability and never reach a persona's prompt; the outgoing guard applies to nudges.
- **The panel** takes paths only from the registry, sits behind the Bearer middleware, escapes the new line, and degrades every bad file to `null`.
