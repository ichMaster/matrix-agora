### #1 — weakly-referenced reply tasks
**Failure scenario:** the agent schedules a 4-second delayed reply; a GC pass collects the un-referenced
task mid-sleep; the reply never arrives and nothing is logged — exactly the "bot randomly stays silent"
bug that is miserable to chase later.
**Anchor:** `agents/agent.py` `on_message` → `asyncio.create_task(...)`.
**Fix:** `self._tasks.add(task)` + `task.add_done_callback(self._tasks.discard)`; pin with a test.
