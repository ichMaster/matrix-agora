## v1.1 — Gemini replies

### AGORA-012 — Gemini replies: history buffer, transcript, LLM seam, typing

**Description:**
Replace the echo with an async Gemini call behind an injectable seam; keep every decision pure and tested.

**What needs to be done:**
- History buffer: the last `HISTORY_N` (default 30, from `.env`) `RoomMessageText` events in `ROOM_ID` —
  **including the agent's own and the other agent's** — as `(name, text)` pairs; pure, bounded.
- Transcript assembly (pure): one `"Name: text"` line per message.
- System instruction (pure): persona + «Ти — <name>. Відповідай лише від себе, коротко, без префікса з
  іменем» (the literal Ukrainian instruction).
- LLM seam `agents/llm.py`: async `generate(transcript, system_instruction) -> str | None` over
  `google-genai` (`gemini-2.5-flash`, `max_output_tokens=400`, `thinking_budget=0`); any failure or empty
  text → `None` + a log line (no texts/keys in logs); injectable fake in tests.
- Agent wiring: reply gate stays owner-only (`should_reply`, renamed from `should_echo`; v1.2 will replace
  it); `room_typing(True)` before the call, `False` in `finally`; send as `m.text`; `None` → stay silent.
- `.env.example`: add `HISTORY_N=30`.

**Dependencies:** None

**Expected result:**
The owner's message gets an in-character Gemini reply; everything but the HTTP call is unit-tested.

**Acceptance criteria:**
- [ ] **Tests:** history cap + own/other inclusion, transcript format, instruction literal, failed/empty
      reply → no send + typing reset (fake LLM), the owner-only gate — Gemini mocked, no network
- [ ] **Contract:** the transcript format `"Name: text"` and the prompt literal are pinned by tests (no doc change)
- [ ] **Gates:** lint ✓ tests ✓
