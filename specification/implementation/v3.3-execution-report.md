### AGORA-033: Simulation registry + the panel skeleton
**Status:** completed · **Commit:** 8ce58fd · **GitHub:** #33
- `simulations.toml` (one entry, `agora`); `agents/registry.py` (shared by the agents and the panel — moved out of
  `panel/` because the agents' config needs it); `agents/<name>.toml` gains `simulation` and a panel-only `[panel]`
  table (English display name and role); `load_config` resolves `HOMESERVER` / `ROOM_ID` through the entry's

  `tests/test_panel_api.py`.
