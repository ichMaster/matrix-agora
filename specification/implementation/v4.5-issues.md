## v4.5 — Claude the philosopher

### AGORA-065 — The philosopher mode: `claude_mode`, the brief, the wider window, the effort

**Description:**
Each Claude reply picks a mode from the message it answers: **direct** when that message names him, **philosopher**
otherwise. Touches `agents/turns.py` (or `agents/logic.py`), `agents/agent.py`, `agents/responder.py`,
`agents/claude_sdk.py`, `server/docker-compose.yml`, `server/claude.env.example`, ARCHITECTURE and the tests.

**What needs to be done:**
- **`claude_mode(answered_text, name_forms, user_id) -> "direct" | "philosopher"`** (pure): direct when the message
  he answers names him — any of his name forms or his Matrix id — else philosopher.
- **The message he answers:** the owner's message for an answer to the owner (R1, the fallback), the trigger
  message for an agent-to-agent reply (R2) — kept as text per event id, bounded like the timeline.
- **`CLAUDE_BRIEF_PHILOSOPHER`** (Ukrainian, in `agents/logic.py`): he is Claude («Клод»), joining a small group chat
  unasked; he finds the metaphorical image the talk keeps circling (often seeded by Кіт's sky, shell lines and
  telegrams) and reflects on its philosophy in 2–4 sentences — a thought, not a lecture; he may name an idea or a
  thinker if it fits; names the members and never discusses what they are; answers `PASS` when no image is worth it.
- **The wider window:** a second RAM buffer of the last `CLAUDE_HISTORY_N` room messages (default 150), seeded from
  the room at start (the backfill fetches the larger of the two windows for the assistant) and never written to
  disk; the philosopher's transcript is that window, the direct mode's stays `HISTORY_N`.
- **The effort:** the philosopher thinks — `effort="high"` and thinking `adaptive` (the output cap is none since the
  v4.4 review, so thinking cannot cut him); the direct mode keeps thinking off. `Turn` carries the mode's effort.
- **`CLAUDE_HISTORY_N`** joins the shared settings interpolated into the `claude` service (so the panel and the
  docs know it) with its default.

**Dependencies:** None

**Expected result:**
A Claude reply to a message that does not name him uses the philosopher's brief, the wider window and a higher
effort; one that names him is unchanged.

**Acceptance criteria:**
- [ ] `claude_mode` is direct for every name form (Ukrainian cases, «Claude», the Matrix id) and philosopher for an
  unnamed message.
- [ ] The direct mode's brief, window (`HISTORY_N`) and options (thinking off) are as in v4.4; the philosopher's
  brief, window (`CLAUDE_HISTORY_N`) and options (`effort="high"`, adaptive thinking) are used otherwise.
- [ ] The philosopher's brief passes the outgoing guard and the persona scan rules (names only, no one's nature).
- [ ] **Tests:** `claude_mode` (every name form, the id, unnamed), the agent choosing the mode from the answered
  message (owner and agent triggers), the window sizes and seeding, the options per mode — the SDK faked.
- [ ] **Contract:** the prompt (an assistant's two briefs), env names (`CLAUDE_HISTORY_N`) — ARCHITECTURE §Canon,
  §Prompt assembly, §Configuration and §Contracts updated, pinned by `tests/test_logic.py`,
  `tests/test_claude_sdk.py` and `tests/test_compose.py`.
- [ ] **Gates:** lint · tests · compose.
