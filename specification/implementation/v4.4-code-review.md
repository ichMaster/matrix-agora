## Findings

### 1. 🔴 Thinking eats the output cap
**Where:** `sdk_options` ([agents/claude_sdk.py](../../agents/claude_sdk.py)).
The bundled CLI enables thinking unless `MAX_THINKING_TOKENS=0` or a settings file disables it — and `setting_sources=[]` reads none. Opus thinks adaptively, and thinking counts against `CLAUDE_CODE_MAX_OUTPUT_TOKENS`. A question that needs a little reasoning hits the cap with no text; the CLI marks the result an error and may make up to 3 "resume" calls, each on the subscription. **Fix:** thinking disabled (`thinking={"type": "disabled"}` and `MAX_THINKING_TOKENS=0`). The brief keeps answers to 1–3 sentences; 300 tokens stay enough.

### 2. 🟠 The init check fails open
**Where:** `respond` ([agents/claude_sdk.py](../../agents/claude_sdk.py)).
If no init message arrives, `blocked` stays `None` and the reply is sent; the SDK defines `SystemMessage` subclasses, and one carrying `apiKeySource='ANTHROPIC_API_KEY'` is not matched by the exact class name. **Fix:** a per-query `saw_init` is required (no init → silent, logged); init is any message with `subtype == "init"` and a `data` dict; on a bad init the stream is closed at once.

### 3. 🟠 CLI error text into the room
**Where:** `respond`.
Text is collected from every assistant message, including one whose `error` is set («API Error: Claude's response exceeded the 300 output token maximum.»); with `result=None` it is returned and passes `trim_to_sentence`. **Fix:** assistant messages with `error` are skipped; their text is used only when the result is not an error; parts are joined with a newline.

### 4. 🟠 An overage reply goes out
**Where:** `respond`, `_rate_limit`.
The CLI bills a `rejected` window with overage allowed as extra usage, and the reply is sent. **Fix:** a query that saw `rejected` (or `isUsingOverage`) drops its reply and logs it `ok=False`; a result with `api_error_status == 429` mutes him as a rejection does.

### 5. 🟠 The turn settings copied by hand
**Where:** `server/docker-compose.yml` (the `claude` service), `server/claude.env.example`.
Claude must compute waves and reservations from the same settings as everyone; they came from a second, hand-kept copy. **Fix:** the `claude` service takes `ROOM_ID`, `OWNER`, `TIMEZONE`, `HISTORY_N`, `REPLY_MAX_TOKENS`, `MAX_BOT_TURNS`, `OWNER_REPLIERS`, `FALLBACK_S`, `BOT_REPLY_P`, `REPLY_DELAY_S`, `BOT_WINDOW_S`, `CAT_REACT_P` and `CAT_PURR_P` from the shared file by interpolation — only those names, no secret — and `claude.env` keeps only Claude's own (`CLAUDE_PASSWORD`, `CLAUDE_CODE_OAUTH_TOKEN`, `CLAUDE_MODEL`, `CLAUDE_CODE_MAX_OUTPUT_TOKENS`).

### 6. 🟠 A stale status and a forgotten mute
**Where:** `ClaudeSdkResponder.__init__`.
**Fix:** at start the responder reads the status file, keeps a `muted_until` still in the future, resets `auth` and the last error, and writes a fresh status (model, `updated_at`).

### 7. 🟠 Transcripts in the tmpfs
**Where:** `sdk_options`, the `claude` service's tmpfs.
`CLAUDE_CODE_SKIP_PROMPT_HISTORY=1` turns off prompt history (the CLI reports «Transcript saving is off»), but nothing turns off session persistence explicitly, and the tmpfs has no size. **Fix:** `--no-session-persistence` (`extra_args`; accepted by the bundled CLI in the SDK's stream-json mode) and `size=64m` on the tmpfs.

### 8. 🟠 The guard and Claude's vocabulary
**Where:** `BANNED_RE`, `outs_a_persona` ([agents/logic.py](../../agents/logic.py)); the persona TOMLs.
Too lenient for Claude: «Ада і Бруно — такі самі агенти, як я.», «Бруно — персонаж…», "Ada and Bruno are bots too." pass. **Fix now:** `агент…`, `персонаж…` and the English `bot…`, `model…`, `agent…` join the banned words; the Latin «ada» and «bruno» join their name forms (they also address them). **Deferred → v4.5:** the pronoun rule (review v4.2 #4) silences Claude's honest explanation of AI when it addresses someone «ти»; v4.5 makes Claude talk more, and whether the assistant keeps the pronoun rule is a decision for that phase.

### 9. 🟡 A warning mutes for a week
The CLI's warning thresholds track the pace within a window; one early-week burst mutes Claude until the weekly reset. **Fix:** a warning mutes him for an hour (`WARN_MUTE_S`) and the next call re-checks; a rejection still waits for `resets_at`.

### 10. 🟡 The forbidden list and the connectors
**Fix:** the forbidden set gains `CLAUDE_CODE_API_KEY_FILE_DESCRIPTOR`, `CLAUDE_CODE_MANAGED_SETTINGS_PATH`, `CLAUDE_CODE_API_BASE_URL` and `CLAUDE_CODE_HOST_CREDS_FILE`; `strict_mcp_config=True` and `ENABLE_CLAUDEAI_MCP_SERVERS=false` keep the account's connectors out, and the init check also requires no MCP servers. The scrub test checks the agent's environment for real.

### 11. 🟡 No timeout
**Fix:** the stream is consumed inside `asyncio.wait_for` (`CLAUDE_TIMEOUT_S`, 90 s) under `contextlib.aclosing`; `CLAUDE_CODE_MAX_RETRIES=2`. A timeout is silence, logged.

### 12. 🟡 Cached input not counted
**Fix:** `prompt_tokens` = input + cache read + cache creation, as Gemini's prompt count includes its cache; the cache columns stay.

### 13. 🟡 «0.0000» for the subscription
**Fix:** the Tokens tab's per-kind cost stays `null` unless a row has one and renders «—»; « · cost» is added only when there is a cost.

### 14. 🟡 «OAuth ✓» with a dead token
**Fix:** the status file records the last error (`subtype` and `api_error_status`, never text) and clears it on success; the card shows it as a red pill.

### 15. 🟡 Backup copies of the secret file
**Fix:** `.gitignore` and `.dockerignore` ignore `server/*.env*` except `server/*.env.example`.

### 16. 🟡 Spec drift
**Fix:** ARCHITECTURE: the panel container also reads `claude.env` (compose needs it to create Claude's container) in §Security's row; `CLAUDE_CONFIG_DIR` is set by compose; the token table's billing column; the status file's fields; both agent packages public on GHCR.

### 17. 🟡 The telegram's length
**Fix:** the material asks for «до 40 слів», so the cap (45) is a safety net, not a cut.

### 18. 🟡 One image tag for two images — DEFER → backlog
A rollback to a pre-v4.4 tag has no Claude image; `deploy.sh` stops. A `CLAUDE_IMAGE_TAG` falling back to `AGENT_IMAGE_TAG` would decouple them.

## What's solid

- **No silent API key:** the SDK passes the CLI `os.environ` (minus `CLAUDECODE`) plus `options.env`, so refusing at startup and scrubbing `os.environ` is the right layer; errors name variables, never values; `apiKeySource` is `"none"` under the OAuth token.
- **No secret reaches an image, git or a log:** the Dockerfiles copy only code; `deploy.sh` prints rsync's file names only; the env files are 0600 locally and on the host.
- **Compose isolation:** the `claude` service loads only its own env file; the tmpfs ownership matches uid 1000; a test checks every service and example for the forbidden names; no panel view exposes a container's environment.
- **The panel** escapes the new lines, degrades a bad status file to `null`, and prices only `api` tokens.
- **The SDK's rate-limit shapes** (epoch-second `resets_at`, odd values) never crash; typing resets in `finally`; a blocked reply is never sent.
