# v5.5 — Issues

Issues for phase **v5.5 — Four more people: пан Леон, Мія, пані Ірма and Кіра** (version **v5 — Voice: Hermes, the
agents hear and speak**), derived from the Tasks and DoD in [ROADMAP.md](../ROADMAP.md) §v5.5 and the contracts in
[ARCHITECTURE.md](../ARCHITECTURE.md). This file covers one phase; ids continue from the previous phase
(AGORA-098 → **AGORA-099…102**).

Four new `persona` members join Agora, built like Ada and Bruno, with a shared past and a friction with every
member, and each with their own voice. The drafts of their canons and life stories exist, discussed with the owner
on 2026-10-20 ([features/v5.5-people.md](../features/v5.5-people.md)). The radio theatre is a later version.

**Reconciled with the code and the live setup (2026-10-20, read-only):**
- **The code is roster-driven.** These follow from `simulations.toml` + `agents/<name>.toml`:
  - turn-taking (R1/R2, the group address, the ranking);
  - the moves' addressees;
  - the outgoing guard's personas;
  - Hermes's members and the recording's voices (`<NAME>_VOICE_ID`);
  - the panel's cards and settings;
  - the speakers' voice alias;
  - the password (`<NAME>_PASSWORD`, `agents/config.py`).
- **Drift: names written into text.** Claude's three briefs (`CLAUDE_BRIEF_DIRECT`, `CLAUDE_BRIEF_PHILOSOPHER`,
  `CLAUDE_NEWS_BRIEF`) say «Ich, Ада, Бруно і Кіт». Hermes's canon names «Ада, Бруно, Кіт, Клод» twice.
  `common.md` names the room's five.
- **Pinned lists.** The member list is pinned in:
  - `tests/test_compose.py`: the service set, the persona loop, the `voice.env` readers;
  - `tests/test_roster.py`, `tests/test_registry.py`, `tests/test_panel_api.py`;
  - `tests/test_panel_settings.py`, `tests/test_settings.py` (who a setting concerns);
  - `tests/test_life.py` (the life files checked).
- **The voice budget.** `VOICE_MONTHLY_CHARS` is 200,000 live since 2026-10-20. The code default, the env examples
  and Claude's compose default are still 100,000 (pinned by `tests/test_settings.py` and `tests/test_compose.py`).
- **Already done live:**
  - the four voice ids are in `server/.env` (`LEON_VOICE_ID`, `MIA_VOICE_ID`, `IRMA_VOICE_ID`, `KIRA_VOICE_ID`);
    the voice prompts are in `docs/elevenlabs-voices.md`;
  - the quieter room settings (`MAX_BOT_TURNS` 4 / `BOT_WINDOW_S` 900, `BOT_REPLY_P` 0.45, …).
- **Accounts.** `@leon`, `@mia`, `@irma` and `@kira` don't exist yet (profile 404). Registration is closed (v0.4), so
  the owner creates them in the admin room.
- **Display names.** The existing ones are Continuwuity's defaults («ada 🏳️‍⚧️»). The transcript uses the roster's
  names, not display names, so they stay out of scope.
- **Prompt size.** Kira's life section is ~13,400 characters, about twice Ada's (~6,400; the owner asked for the
  detail).
