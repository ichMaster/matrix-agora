## v4.3 — The cat: his past life and his initiative

### AGORA-055 — The past-life theses: the `pastlife` capability, `pick_memory`, retold never verbatim

**Description:**
The cat's authored theses (`agents/canon/kit.memories.md`, 93 lines `- [tags] text`, drafted 2026-10-10) enter his
spoken lines: one is picked by the talk and retold in his own words, never quoted. Touches `agents/roster.py`,
`agents/config.py`, a new `agents/pastlife.py`, `agents/logic.py`, `agents/agent.py`, `agents/kit.toml`, both
`.env.example` files, ARCHITECTURE.md and the tests.

**What needs to be done:**
- **A capability and a path.** `pastlife` joins `CAPABILITIES`; the `creature` type has it, a persona does not. The
  TOML gains `memories` (the theses file), required with `pastlife` — `Member.memories` like `natal`, and
  `load_config` reads it into `AgentConfig.theses`; a missing, empty or malformed file refuses to start.
- **`agents/pastlife.py` (pure):**
  - `parse_theses(text) -> tuple[Thesis, ...]` — `Thesis(tags, text)`; only lines `- [a, b] text` count, headings and
    prose are ignored; a line that starts with `- [` but does not parse is an error naming the line.
  - `pick_memory(event_id, last_text, theses, told) -> int | None` — the index of the thesis to retell:
    - candidates are the theses not in `told`; when all are told, all are candidates again;
    - a candidate whose tag occurs in `last_text` (lowercase substring, apostrophes `’ʼ` normalised to `'`) is
      preferred;
    - among the pool, `uniform(event_id, "memory")` picks one — deterministic, no shared state.
- **When he remembers.** In a spoken (non-purr) reply, with probability `CAT_MEMORY_P` (default 0.25, the injected
  `rng`), `pick_memory` (the latest timeline event id, the message he answers) chooses a thesis and the prompt gains
  «Спогад з минулого життя (перекажи своїми словами, уривком, не цитуй): <text>» — after «Настрій дня», before the
  rules. `told` is RAM only; a thesis is marked told when a line built on it is sent.
- **Never verbatim.** A reply that copies 5 or more consecutive words of the thesis (`shares_span(reply, thesis, 5)`,
  `agents/chronicle.py`) is regenerated once; if it still copies, the cat stays silent (`silent: verbatim memory`).
  The word cap, the outgoing guard and R3 apply as before.
- **The content rule, pinned:** no thesis names Ich, Ada or Bruno — checked with the roster's name forms (word
  boundaries, as `mentions` does), and no thesis says 2038 or holds a banned word (`BANNED_RE`).

**Dependencies:** None

**Expected result:**
Now and then a spoken line of the cat carries a fragment of his past life, chosen by what was just said, in his own
words.

**Acceptance criteria:**
- [ ] `parse_theses` reads all 93 theses of `kit.memories.md`; malformed lines are named errors; a creature without a
  readable `memories` file refuses to start.
- [ ] `pick_memory` is deterministic per event id, prefers a tag found in the message, never repeats until all are
  told, and starts over after that.
- [ ] A chosen thesis enters the cat's prompt in contract order; a persona's prompt never has the section.
- [ ] A reply copying 5+ words of its thesis is regenerated once, then dropped.
- [ ] **Tests:** `tests/test_pastlife.py` (parsing, the 93 theses, determinism, tag preference incl. a Ukrainian case
  form and an apostrophe variant, no repeats, reset, the content rule over the real file); the agent's reply path
  with a fake LLM (the section appears with `CAT_MEMORY_P` 1.0 and never with 0.0; the verbatim reply regenerated
  once then silent; `told` grows only on a sent line); `test_roster` (the `pastlife` capability, `memories` required
  with it). nio and Gemini mocked.
- [ ] **Contract:** the TOML schema (`memories`, the `pastlife` capability) and the prompt order (the creature's
  «Спогад з минулого життя» after «Настрій дня») — ARCHITECTURE §Canon, §Prompt assembly, §Contracts and
  §Configuration (`CAT_MEMORY_P`) updated, pinned by `tests/test_roster.py`, `tests/test_logic.py` and
  `tests/test_compose.py` (the env example carries `CAT_MEMORY_P`).
- [ ] **Gates:** lint · tests.

### AGORA-056 — The cat starts conversations: `nudge_due`, `nudge_kind`, `state/kit.nudge.json`

**Description:**
After a quiet daytime stretch the cat posts one line tied to the recent talk — a past-life fragment, a Linux line or
his horoscope as a metaphor. He is the only agent who ever posts without a trigger. Touches a new `agents/nudge.py`,
`agents/agent.py`, `agents/turns.py`, `agents/logic.py`, `agents/roster.py`, both `.env.example` files,
ARCHITECTURE.md and the tests.

**What needs to be done:**
- **A capability.** `nudge` joins `CAPABILITIES`; the `creature` type has it, a persona does not — the code path that
  posts without a trigger runs only with `nudge`.
- **`agents/nudge.py` (pure):**
  - `nudge_due(now_ms, local_now, last_room_ms, last_nudge_ms, nudges_today, idle_ms, per_day, hours) -> bool` — all
    of: the room quiet for `idle_ms` (the last room message, purrs included; no message counts as quiet), the last
    attempt at least `idle_ms` ago, fewer than `per_day` today, the local hour inside `hours` (`"09-22"` = 09:00 ≤ t
    < 22:00).
  - `nudge_kind(day, n) -> "memory" | "command" | "horoscope"` — `uniform(f"{day}:{n}", "nudge")`, deterministic.
  - `load_nudge_state(path, day)` / `save_nudge_state(path, state)` — `{"last_ms", "day", "count", "sent_ms"}` (`sent_ms` added in AGORA-057), no texts; the
    count resets on a new day; a missing or corrupt file is a fresh state; written atomically, 0600.
- **The watcher.** `idle_watcher` checks `nudge_due` for an agent with `nudge` (the clock injected); the settings
  `CAT_NUDGE_IDLE_S` (1200 — the owner's choice, 2026-10-10; drafted as 2700), `CAT_NUDGES_PER_DAY` (6), `CAT_NUDGE_HOURS` (`09-22`, Kyiv = `TIMEZONE`).
- **The line.** One model call (kind `reply`): `build_prompt` (canon → life → world → mood) plus the material by kind,
  then the nudge rule («Ти сам починаєш розмову: один короткий рядок, що пов'язує це з тим, про що недавно говорили.
  Не вітайся і не питай, чи є хтось.»), the last `HISTORY_N` lines as the transcript.
  - `memory` — `pick_memory` with the recent talk as `last_text`, the never-verbatim rule of AGORA-055;
  - `command` — «Кинь один рядок команди Linux чи скрипту — лише як текст, — що пасує до розмови.»;
  - `horoscope` — «Перекажи свій сьогоднішній гороскоп метафорою про останню розмову.»; without the day's mood it
    becomes `memory`.
  - Then the reply pipeline's checks: trim, `clean_reply`, `strip_pass`, `cap_words`, duplicate, `outs_a_persona`.
  - **Pre-send:** a room message that arrived during generation drops the nudge (the room is no longer quiet).
  - Every attempt sets `last_ms`; only a sent nudge adds to `count`. Logs `nudge sent (<kind>)` / `nudge silent:
    <reason>` — never the text.
- **A fresh wave.** A nudge is an ordinary agent message, never a purr; the quiet stretch has emptied the wave
  window, so the others treat it by R2 — one next speaker, the usual `BOT_REPLY_P` and limits.
- **Carried in from the v4.2 review (#13):** `pending_answers` counts arrivals over the whole timeline, so the cat's
  spoken answer to the owner that the model words as a bare purr («Мрр.») releases his reservation at once instead of
  holding the wave until `FALLBACK_S`.

**Dependencies:** AGORA-055

**Expected result:**
After a quiet stretch in the daytime, Кіт drops one line tied to the recent talk; at night and over the daily cap he
stays silent, and nobody else ever posts unprompted.

**Acceptance criteria:**
- [ ] `nudge_due` fires only with silence, the gap, under the cap and inside the hours; a restart reads the state file
  and neither re-nudges at once nor exceeds the cap.
- [ ] `nudge_kind` is deterministic per day and number and yields all three kinds.
- [ ] A nudge is sent with the right material, passes the same checks as a reply, and is dropped when the room spoke
  during generation; `state/kit.nudge.json` holds no text and is 0600.
- [ ] A persona never nudges (no `nudge` capability), whatever the silence.
- [ ] **Tests:** `tests/test_nudge.py` (`nudge_due`: silence, gap, cap, hours, an empty room, day rollover; `nudge_kind`;
  state load/save incl. corrupt and old-day files; the agent's nudge with a fake LLM — sent, material per kind, the
  horoscope fallback, the pre-send drop, PASS/guard silence counts as an attempt only; a persona never nudges); a
  turn-taking test that a nudge after silence opens a fresh wave with exactly one next speaker among Ada and Bruno;
  the #13 regression (a purr-worded spoken answer releases the reservation). Clock, rng, nio and Gemini injected or
  mocked.
- [ ] **Contract:** env names (`CAT_NUDGE_IDLE_S`, `CAT_NUDGES_PER_DAY`, `CAT_NUDGE_HOURS`), the state file
  `<name>.nudge.json`, the `nudge` capability and the turn-taking rule "the cat is the only initiator" — ARCHITECTURE
  §Turn-taking, §Configuration, §Data and state files and §Contracts updated, pinned by `tests/test_nudge.py`,
  `tests/test_roster.py` and `tests/test_compose.py`.
- [ ] **Gates:** lint · tests.

### AGORA-057 — The cat's card: his theses, his last nudge and today's count

**Description:**
The panel shows what v4.3 adds to the cat: how many past-life theses he has, when he last started a conversation and
how many he started today. Touches `panel/registry.py`, `panel/memory.py`, `panel/app.py`, `panel/static/app.js`,
`specification/design/README.md` and the tests.

**What needs to be done:**
- **The registry** carries each agent's `memories` path (from `Member`), like `natal` — the registry's own path,
  never request data.
- **`GET /api/agents/{name}/memory`** gains, for an agent with `pastlife` and/or `nudge`: `pastlife: {"theses": N}`
  (parsed with `agents.pastlife.parse_theses`; `null` when unreadable) and `nudge: {"last": iso | null, "today": n}`
  (from `state/<name>.nudge.json`, today's count 0 on another day); both `null` for an agent without them. Bad files
  degrade to `null`, never a 500.
- **The card** (an agent with `pastlife`/`nudge`): a line under "Mood of the day" — «93 theses · last nudge 14:05 ·
  2 today» (or «no nudge yet»); the Mood tab repeats it. English UI, `esc()` on everything.
- **The design README** addendum notes the line on the creature card.

**Dependencies:** AGORA-056

**Expected result:**
Кіт's card tells how many theses he holds, when he last spoke first and how often today.

**Acceptance criteria:**
- [ ] The memory view carries `pastlife` and `nudge` for the cat and `null` for Ada and Bruno; a corrupt nudge file or
  an unreadable theses file degrades to `null`.
- [ ] The card and the Mood tab show the line; nothing for a persona.
- [ ] **Tests:** `tests/test_panel_memory.py` (the sections, the day rollover, corrupt files, the route with the token
  and 401 without); `tests/test_panel_static.py` (the card line and its guard by capability); `node --check
  panel/static/app.js`.
- [ ] **Contract:** the panel API (the memory view gains `pastlife` and `nudge`) — ARCHITECTURE §The panel and
  §Contracts updated, pinned by `tests/test_panel_memory.py`.
