### AGORA-193: `/scan`, `/scan yes`, `/scan all`: the counts, the kept list and closing it

**Status:** completed · **Commit:** a9dc9b0 · **GitHub:** #193

**Gates:** [x] lint · [x] tests · [x] compose (`server/kira.env.example` changed)

**What was built:**
- `scan_answer`: `/scan` answers «⚙️ Сканую…» and scans in a spawned task. A second `/scan` meanwhile gets «⚙️
  Сканування вже йде», and with no key the scan is off.
- `scan_once` and `scan_items`:
  - It reads open private lines and thoughts in the range, open facts not read before (`facts_seen`, by hash), and
    the `hour`/`day` summaries written in the range.
  - It keeps `state/<name>.scan.json` (0600, atomic; refs, codes, hashes and times, never a text).
  - `last_end_ms` moves only when the list is used or nothing was found.
- `scan_close`: within `SCAN_TTL_S`, once, the list spent before anything closes:
  - a line becomes `blocked` and goes through `close_lines`;
  - a thought becomes `blocked`;
  - a fact gets `set_mark`;
  - a summary is removed with `Archive.talk_delete`.

  Nothing is ever opened.
- `OPUS_JUDGE_KEY` is popped at start. The `SCAN_*` agent settings are added, and `COMMANDS` gains `scan` (and so
  `setMyCommands`).
- ARCHITECTURE: the `/scan` paragraph, the state file row, the configuration rows and the kira.env example keys.

**Found while testing:** a fact has only its day, so every scan of the same day would have read the day's facts
again. The scan file now keeps the facts a used or an empty scan read, by hash (`facts_seen`), and never reads them
again.
