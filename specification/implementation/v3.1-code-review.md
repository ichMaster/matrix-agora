## Findings

### 1. 🟠 A well-formed line with a non-integer count crashes the report
`agents/usage.py:34` — `parse_lines` checks only that the line is JSON with a parseable `ts`. A line such as
`{"ts": "2026-10-03T10:00:00", "prompt_tokens": "12"}` (a hand edit, or a future writer bug) passes, and
`aggregate` then does `row.prompt += "12"` → `TypeError`: the whole report dies instead of skipping one line.
The DoD requires the report to survive a corrupt line.
**Fix:** validate the record shape in `parse_lines` — a dict; `ts` a string with an ISO date; `agent`/`kind`
strings; the three counts `int` (not `bool`) or `null`; `ok` a bool — and count anything else as corrupt.

### 2. 🟡 The usage file is created with the umask mode, then chmod'ed
`agents/agent.py:424` — `open("a")` creates `state/<name>.usage.jsonl` as 0644 (typical umask) and the mode
is fixed one call later; it also costs a `chmod` on every Gemini call. The lines hold only counts, but every
other `state/` file is private from birth.
**Fix:** `os.open(path, O_WRONLY | O_APPEND | O_CREAT, 0o600)`; keep the `chmod` only as a guard for a file
that already exists with a looser mode.

### 3. 🟡 `--days 0` or a negative value silently prints "no data"
`agents/usage_report.py` — `since = today - (days - 1)` lies in the future for `days < 1`, so the report
prints "no data" as if nothing was spent.
**Fix:** an argparse type that rejects values below 1.

### 4. 🟡 The cost would undercount if thinking were ever enabled
`agents/usage.py:28` — `output_tokens` is `candidates_token_count`; Gemini bills thinking tokens as output.
With `thinking_budget=0` (today) `thoughts_token_count` is empty and the cost is exact.
**Defer → backlog:** if thinking is ever turned on, add `thoughts_tokens` to the line (a contract change)
and to the cost.

### 5. 🟡 The report reads every usage file whole; the files grow forever
`agents/usage_report.py` — about 180 bytes per call: a few MB a year at today's pace, fine for the PoC.
**Defer → v3.3:** the panel reuses this aggregation; rotation or a per-month file is decided there.

### 6. 🟡 A torn last line swallows the next record
If the process dies mid-write, the next append lands on the same line and both records become one corrupt
line (skipped with a warning). One small `O_APPEND` write makes this very unlikely.
**Defer → backlog:** start each append with a newline if the file does not end in one.

## What's solid

- No text can reach a line: the fields are counts, the constant model name and a `kind` chosen by code.
- Every path is accounted: ok, empty and raised calls all report; a failing sink or a write error is logged
  and swallowed, and the reply still goes out (tests drive all three).
- `usage_metadata` missing or partial → `null`s, never a crash.
- Prices come only from `.env`; an unset or invalid price drops the cost column with a warning.
- The `kind` list is pinned against ARCHITECTURE (now with `digest`), and a test drives every call site.
- The day buckets and the `--days` window both use local time in `TIMEZONE`, so they agree.
