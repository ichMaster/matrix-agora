## Findings

### 1. 🟡 `mia` names Mia in Italian
`agents/mia.toml` `name_forms` includes the Latin `mia`. `mentions` matches any form as a whole word.

**Failure scenario:** Ada, who reads Calvino in Italian, writes «Це la mia città, і край». Mia is named, and a
named member always answers (R2, no probability roll). An unasked reply follows.

**Fix:** drop the Latin `mia`; the room writes her name in Cyrillic. The others' Latin forms (`leon`, `irma`,
`kira`) are no common words in the room's languages.

### 2. 🟡 A brace in a brief
`Agent.brief` calls `template.format(members=…)`. A brief that later gains a literal `{…}` (an example, a JSON
hint) raises `KeyError` in Claude's reply path. **Home:** backlog — a `str.replace("{members}", …)`, or a test
that every brief formats.

### 3. 🟡 `members_phrase` readability
`agents/logic.py`. The nested conditional expression is correct (`""`, one name, «a, b і c»). **Home:** cleanup
(/simplify).

### 4. 🟡 Kira's prompt size
`agents/canon/kira.life.md`. The owner asked for much more detail. Noted for the token report.

### 5. 🟡 Display names
`@leon` and the others carry Continuwuity's default display names. The transcript uses the roster's names, so only
Element's view is affected. **Home:** backlog (with avatars, see `docs/portraits.md`).
