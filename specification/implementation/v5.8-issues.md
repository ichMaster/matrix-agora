Voice: Hermes, the agents hear and speak**), derived from the Tasks and DoD in [ROADMAP.md](../ROADMAP.md) §v5.8 and
the contracts in [ARCHITECTURE.md](../ARCHITECTURE.md). This file covers one phase; ids continue from the previous
phase (AGORA-109 → **AGORA-110…115**).

Кіра answers on Gemini 3.1 Pro and keeps Flash for her background calls. She gets Noos's kind of memory: an archive of
every line she sees in Agora and her private chat, with hybrid recall before each reply, and pinned facts about the
owner that only her private prompt carries, the first ones imported once from Noos. She knows Agora in the private
chat, and in Agora she says nothing about him. It builds on v5.6–v5.7's private chat with two doors.

### AGORA-111 — The archive: `agents/archive.py`, the `recall` capability, embeddings and the backfill

**Description:**
A per-agent SQLite archive of every line the agent sees, searchable by words (FTS5) at once and by meaning
(Gemini embeddings) once embedded, with Noos's hybrid fusion as pure functions. Touches `agents/archive.py` (new),
`agents/llm.py` (the embedding call), `agents/roster.py`, `agents/kira.toml`, `agents/agent.py`, `pyproject.toml` /
`uv.lock` (`numpy`), `tests/test_archive.py` (new) and ARCHITECTURE §Memory, §Data and state files.

**What needs to be done:**
- `agents/roster.py`: `recall` joins `CAPABILITIES`, a person's only (`PERSONA_ONLY`), switched on in a person's
  TOML; `kira.toml`: `recall = true`.
- `agents/archive.py`:
  - `state/<name>.archive.db`, created 0600: a table `lines` (`id`, `key` UNIQUE — the Matrix event id, or
    `tg:<update_id>` for Telegram — `ts_ms`, `place` `agora` | `private`, `channel` `matrix` | `telegram`,
    `speaker`, `text`, `emb` BLOB NULL) and an FTS5 index over `text` (`unicode61`); append-only, never pruned; a
    duplicate key is ignored;
  - `append(...)`, `unembedded(limit)`, `set_embeddings(...)`, `search_words(query, places, limit)` (BM25 over FTS5,
    the query's words longer than 2 characters joined with OR, as Noos's), `vectors(places)`, `around(id, n)` (a
    line's neighbours in its place), `today(place, day_start_ms, limit)`, `counts()` (lines, embedded);
  - the pure parts: `fuse(word_ids, meaning_ids, k=60)` (reciprocal rank fusion), `cosine_top(query_vec, ids,
    matrix, n)` (numpy), `pick_recall(ranked, exclude_keys, n)` (the top lines not already in the prompt's history
    window).
- `agents/llm.py`: `GeminiClient.embed(texts) -> list[list[float]] | None` on `gemini-embedding-001`
  (`output_dimensionality` 768), batched; a usage line of kind `embed` (tokens when reported, else nulls); a
  failure is None, logged by type.
- `pyproject.toml`: `numpy` (the cosine over the stored vectors); `uv lock`.
- `agents/agent.py` (only with `recall`):
  - every Agora line the agent sees (the live ones in `on_message`, the restart backfill in `seed_context`) and
    every private line, both doors and both sides (`private_line`, `private_reply`, the Telegram backlog), is
    appended with its key, time, place, channel and speaker;
  - the idle watcher embeds up to 100 unembedded lines a tick; a failed embed is retried next tick, never blocks;
  - **the backfill at the first start** (an empty archive): the whole private room (paged back, bounded at 5,000
    events) and Agora's last 1,500 text lines, from the homeserver (`room_messages`, as `backfill`); Telegram has no
    history to fetch, which the log says once.
  - **the private history at start** comes from the archive's last `HISTORY_N` private lines, both doors, when it
    holds any — so Telegram lines survive a restart (v5.7 code review #5); `last_private_ms` comes from the last of
    them.
- ARCHITECTURE: §Memory (the archive: what it holds, append-only, who has it), §Data and state files
  (`state/<name>.archive.db`, 0600, texts inside, never read by another agent), the usage kind `embed`.

**Dependencies:** None

**Expected result:**
Кіра's archive fills from the chats at her first start and grows with every line; a word search finds a line at
once and a meaning search once it is embedded.

**Acceptance criteria:**
- [ ] Every Agora and private line (both doors, both sides) is appended once; a duplicate key is ignored.
- [ ] The first start backfills the private room and Agora's last 1,500 lines; a later start does not.
- [ ] Embeddings are added in batches by the idle watcher; a failure never blocks a reply.
- [ ] The file is 0600; no text reaches a log.
- [ ] **Tests:** `tests/test_archive.py` with SQLite in a temporary directory and Gemini mocked: append and
      dedupe, the word search (Ukrainian), the embedding batches, the meaning search, `fuse` and `pick_recall`
      (order, the history window left out), `around`, the backfill bounded, the capability's roster rules.
- [ ] **Contract:** the state file and the capability — ARCHITECTURE §Data and state files and §Contracts, pinned
      by `tests/test_archive.py` and `tests/test_roster.py`.
- [ ] **Gates:** lint, tests.

### AGORA-113 — Facts about the owner: `agents/facts.py`, extraction, the marker line, the Noos import

**Description:**

added when he asks her to remember, and seeded once from Noos. Touches `agents/facts.py` (new), `agents/roster.py`,
`agents/kira.toml`, `agents/agent.py`, `agents/private.py`, `agents/settings.py`, `tests/test_facts.py` (new) and
ARCHITECTURE §Memory, §Data and state files, §Token accounting.

**What needs to be done:**
- `agents/roster.py`: `facts` joins `CAPABILITIES`, a person's only, and needs `private` (`NEEDS`); `kira.toml`:
  `facts = true`.
- `agents/settings.py`: `FACTS_MAX` (100), `FACTS_IN_PROMPT` (25), `FACT_MAX_CHARS` (240), `cap:facts`.
- `agents/facts.py`:
  - the store `state/<name>.facts/`: one Markdown file per fact, Noos's header (`pin` 0/1/2, `added`, `source`
    `private` | `agora` | `asked` | `noos`) then the text; files 0600; `load`, `add` (a slug name, never a
    duplicate text), `replace(id, text)`, `remove(id)`, `set_pin(id, pin)`;
  - `facts_section(facts, in_prompt, max_chars)`: pin 1 first, then pin 2 while there is room, pin 0 never;
    «Що ти знаєш про Ich: …»;
  - the marker: the private brief tells her that when the owner asks her to remember something, her answer ends
    with one line `ЗАПАМ'ЯТАЙ: <факт>`; `split_marker(text) -> (clean, facts)` (pure) strips every such line

  - the extraction at a session's end (beside the summary, `GEMINI_MODEL`, usage kind `facts`): the session's
    lines and the current facts → JSON `{"add": [{"text", "pin"}], "replace": [{"id", "text"}]}`; validated (the
    length, the pin, the count under `FACTS_MAX`, a known id); an invalid answer changes nothing; a stale fact is
    replaced, never piled up; the prompt speaks of the owner and of her as a person;
  - **the one-shot import from Noos:** `python -m agents.facts import <dir> [--dry-run]` reads `<dir>/facts/*.md`
    (Noos's format) and `<dir>/import/*/*.md` (README left out), one Flash call condenses them into facts of at most

    log.
- `agents/agent.py`:
  - the private prompt carries `facts_section` after «Сьогодні»; an Agora prompt never does;
  - the facts are read from disk at each private prompt, so a panel edit takes effect at the next answer;
  - the facts are also appended to the archive as `place: facts` lines, searchable only by a private recall (the
    place filter of AGORA-112).
- ARCHITECTURE: §Memory (facts), §Data and state files (`state/<name>.facts/`), §Token accounting (kind `facts`),
  §Contracts (the capability, the marker line).

**Dependencies:** AGORA-110, AGORA-112

**Expected result:**
«Запам'ятай, що …» in the private chat becomes a pinned fact she knows in the next conversation; facts surface only
alone with the owner; the import seeds them from Noos, filtered.

**Acceptance criteria:**
- [ ] The marker line is parsed, stored and never sent, on every path.
- [ ] The extraction adds and replaces within the limits; an invalid answer changes nothing.
- [ ] The prompt block keeps the pins' order and the limits; an Agora prompt never carries a fact.

- [ ] **Tests:** `tests/test_facts.py` with Gemini mocked: the store (0600, slugs, no duplicates), the section,
