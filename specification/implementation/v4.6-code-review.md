## Findings

### 1. 🟠 A question to the owner is answered by someone else
**Where:** `next_speaker` ([agents/turns.py](../../agents/turns.py)); the `ask` addressee ([agents/moves.py](../../agents/moves.py)).

**Failure scenario:**
- About 6% of the personas' replies ask Ich (0.25 × 1/4).
- «Ich, а що ти зараз читаєш?» names no roster member, so R2 picks an unnamed candidate.
- With `BOT_REPLY_P` 0.7, that candidate usually answers the owner's question first.

**Fix:** R2 has no candidate when the message names the owner and no ranked or mention-only member, as with the cat
alone. The owner's name forms (`ich`) live in one constant; ARCHITECTURE R2 is updated and a regression test added.

### 2. 🟡 The cat's affectionate names
**Where:** `agents/kit.toml` `name_forms`.

**Fix:** add `котику`, `котик`, `кіте`. The TOML comment already says any ordinary cat-word addresses him.

### 3. 🟡 Contrarian to a greeting
**Where:** the `disagree` line ([agents/moves.py](../../agents/moves.py)).

**Fix:** the line becomes conditional: disagree only if the message holds a view to disagree with; otherwise answer
as usual. Disagreeing with the owner stays possible when it makes sense.

### 4. 🟡 The addressee and the bridge
The addressees come from every other member. For the cat (ambient) and Claude (ranked) that is wanted. For Лілі's
mention-only bridge (v4.8) it would need a filter, and that phase owns it.

### 5. 🟡 «Інше життя» and «природа»
No change. The cat's past life as a sysadmin is his lore and story, which the room hears from him; it is not a
question about what he is. The human-belief rule binds only the personas, and the outgoing guard covers what is said
about them.

## What's solid

- **Weights:**
  - `nan`, `inf` and negative values fall back to the default and are logged by name only;
  - all zeros means a plain answer every time;
  - a sum above 1 is scaled down.
- **Scope:**
  - only a persona ever gets a move; the cat's nudges, Claude and the session summary never do;
  - the move is drawn from the newest trigger, the same one R3 re-checks, and a resumed reply draws the same move.
- **Chains stay bounded:**
  - a named candidate skips the coin only inside a live burst;
  - the wave limit always binds;
  - asking Claude by name puts him in direct mode, and asking the cat leaves R2 without a candidate.
- **Prompt, config, logs:**
  - the move line sits between the summary and the rules, as ARCHITECTURE says and a test pins;
  - the example values equal the code defaults (pinned);
  - only the kind is logged.
