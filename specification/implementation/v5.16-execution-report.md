### AGORA-156: The search: the smallest blocked set (`agents/probe.py`)
**Status:** completed · **Commit:** 01c3e28 · **GitHub:** #156 (closed)
**Gates:** [x] lint · [x] tests · [ ] compose (n/a)

**As built, differs from the issue:**
- **QuickXplain, not ddmin.** QuickXplain assumes the filter blocks more as more is added. It takes at most 12 calls for
  one item among 40 and 15–19 for a pair; ddmin took 42 for a pair, and at the 12-call cap it would have closed 30
  items.
- **The cap never closes all that is left.** With nothing narrowed, the outcome is `cap` and nothing is closed.

The issues file records both. A test caught a stale call count (`Found(calls, closed=await …)` reads `calls` before the
await runs); it was fixed before the commit.
