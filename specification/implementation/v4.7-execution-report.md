## Detailed Results

### AGORA-073: The schema and the overrides
**Status:** completed · **Commit:** 0d73a3a · **GitHub:** #73
**Gates:** [x] lint · [x] tests · [ ] compose (n/a)

- **The schema:** `agents/settings.py` `SCHEMA` lists 37 non-secret settings in six groups. Each has its kind,
  bounds, code default, unit, description and scope: `shared`, or a type, capability or engine.
- **The defaults are pinned per setting.** Each must equal the agent's own `os.environ.get(NAME, default)`, and
  each must be read by the agents. No secret, id, path or forbidden Claude name is in the schema.
- **At start:** `main()` applies the overrides before anything reads them (code default < env < panel). An unknown
  or invalid one is ignored and logged by its name. The agent logs `settings: overridden <names>` and writes
  `state/<name>.settings.json` (0600).
- **`GEMINI_MODEL`:** it picks the Gemini model, and the usage line names the model called.

### AGORA-074: The settings API
**Status:** completed · **Commit:** 14c6268 · **GitHub:** #74
**Gates:** [x] lint · [x] tests · [ ] compose (n/a)

- **`GET /api/settings`:** the schema, each override, the agents each setting concerns and their effective values.
  An unreadable agent file becomes `null`.
- **`PUT /api/settings`:**
  - it validates `{set, reset}`; a 422 names the setting, and nothing is written;
  - it writes `state/settings.json`;
  - it restarts the running agents the change concerns: every agent for a shared setting, while a stopped one is
    skipped and never started.
- **The route contract and ARCHITECTURE** are updated.

### AGORA-075: The Settings view
**Status:** completed · **Commit:** 5433c7c · **GitHub:** #75
**Gates:** [x] lint · [x] tests · [ ] compose (n/a)

- **Where:** a Settings drawer, reached from the rail or from the top bar on narrow screens.
- **The fields:** grouped cards; each field shows its default and what the agents run with. An override carries a
  «panel» pill and a Reset button.
- **Saving:** a sticky Save names the agents that will restart, and asks for a confirmation first.
- **No lost typing:** the poll never redraws under typing.
- **One request helper:** every state change goes through `send()` (POST, PUT or DELETE, always with the token).
- **The design addendum** (v4.7) is written.
