## Findings

### 1. 🔴 The outgoing guard drops whole digests and answers on ordinary topics
`agents/herald.py` `_think`; `agents/logic.py` `outs_a_persona`.

**Scenario:**
- `DIGEST_BRIEF` has Hermes speak to Ich as «ти». `OTHERS_RE` matches «ти / тобі / він / вони», so any sentence that
  also holds a banned stem trips the guard.
- A probe of 10 plausible digest sentences tripped 10 of 10:
  - «Ада розповідала тобі про улюбленого персонажа з роману»;
  - «Клод приніс новину про нову модель штучного інтелекту, а Бруно…»;
  - «страхового агента».
- The regeneration covers the same topic and trips again, so the stretch is skipped and the owner gets nothing. A
  question gets silence.
- Ada is an editor and Claude brings tech news, so this would be frequent.

**Fix:**
- For the herald, apply the guard per sentence and only through its persona-naming arm: a sentence that holds a
  banned term **and** names a persona is removed. In his text «ти» is Ich.
- The rest of the digest is sent.
- Only an empty result is skipped (see #7).
- ARCHITECTURE §The herald changes accordingly.

### 2. 🟠 A failed digest is never retried after 10 minutes
`agents/herald.py` `digest()` (`new_count = 0` before the model call), `tick()`.

**Scenario:**
- The Pro call fails at 22:00. `new_count` is already 0, and `digest_due` needs ≥ 5.
- No retry happens until five more messages arrive, possibly the next day.
- The reset also wipes the count of lines that arrived while the pages were being read.

**Fix:** take `seen = new_count` before reading. After a sent or skipped digest, set
`new_count = max(0, new_count - seen)`; after a failure, leave it.

### 3. 🟠 A failed page read moves the point past messages never digested
`agents/herald.py` `fetch()`.

**Scenario:**
- 250 messages since the point, and page 2 returns 502.
- The digest covers the newest 100, and `record_sent` moves the point past the other 150.
- If the first page fails, «підсумок» answers `NOTHING_NEW` ("not a word in Agora"), which is false.

**Fix:**
- `fetch` reports whether the read completed: it reached the stop, the bound, or the start of the room.
- An incomplete read fails the digest (retried) and the answer, and never says "nothing new".

### 4. 🟠 A private room made in this run is trusted for the whole run
`agents/herald.py` `ensure_private_room`.

**Scenario:** the owner declines the invite. The sync shows the room without him, but every digest (with paid TTS)
still goes there until a restart.

**Fix:** trust a room made in this run only while the sync has not brought it back yet. Once it is in
`client.rooms`, the membership check applies.

### 5. 🟠 With only `PRICE_MODELS` set, the reports print $0 and the panel hides the note
`agents/usage.py` `daily_report`; `panel/memory.py` `usage_view`; `panel/static/app.js`.

**Scenario:** both shipped env examples leave `PRICE_INPUT/OUTPUT_PER_1M` empty and set `PRICE_MODELS`.
- `priced` turns true, and `cost()` is None for every total with Flash tokens.
- The report prints «$0.0000 · projected month $0.00» and still says "No prices set".
- The panel drops its "Prices are not configured" note, and Flash rows show "—" unexplained.

**Fix:**
- A None cost prints "—", never `or 0.0`.
- The header lists the prices that are set.
- The panel shows the note whenever the default pair is missing.

### 6. 🟠 The panel accepts voice ids the runtime refuses
`agents/settings.py` `ID_RE` vs `agents/voice.py` `VOICE_ID_RE`.

**Scenario:**
- `HERMES_VOICE_ID=abc123XYZ` saves, and the card shows voice on.
- Every digest logs "the voice id is malformed", goes out as text, and records a failed `tts` usage line.

**Fix:**
- One pattern, empty or `[A-Za-z0-9]{10,40}`, shared by the schema and the voice.
- At start a malformed id makes him text-only, with no `tts` line.

### 7. 🟡 A skipped stretch corrupts the counts
`agents/herald.py` `digest()`.

**Scenario:** `replace(record_sent(...), count=self.state.count)` writes today's day with the previous day's count.

**Fix:** keep the day's count as it is for today (`today_count`), folded into #1.

### 8. 🟡 A stop during a digest sends it twice after the restart
`agents/herald.py` `run()`.

**Scenario:** a deploy's SIGTERM cancels the digest after the voice was posted but before the state was saved. The
restart digests the same stretch again: double TTS and a double message.

**Fix:** on stop, close the sync first, then wait up to 20 s for a running digest or answer (compose allows 30 s)
before cancelling and closing the client.

### 9. 🟡 Edits count as new messages
`agents/herald.py` `on_message`, `fetch()`.

**Scenario:** an edit (`m.relates_to.rel_type == "m.replace"`, body «* …») parses as `RoomMessageText`.
- An edited question gets a second Pro answer.
- An edited «підсумок» makes a second digest.
- An edited Agora line appears twice in a digest.

**Fix:** a pure `is_edit(event)`; Hermes skips edits everywhere.

**Deferred:** the speakers have the same gap from before v5.1 (ARCHITECTURE rule 4 says edits never trigger a
reply). → backlog.

### 10. 🟡 `server/.env.example` points the key at the shared file
`server/.env.example` (the copied comment "dev mode: HERMES_PASSWORD and ELEVENLABS_API_KEY in this file").

**Scenario:** following the comment would give every Gemini container Lumi's key.

**Fix:** the server example says they live in `server/hermes.env` only, and a test pins that no example comment
points the key at a shared file.

### 11. 🟡 The agent Tokens tab drops `sky` rows
`panel/static/app.js` `KIND_ORDER`.

**Scenario:** the cat's `sky` calls are in his total but not in his kind rows.

**Fix:** list `sky` in `KIND_ORDER`, and append any unlisted kind.

### 12. 🟡 Malformed `PRICE_MODELS` entries are ignored silently in the panel
`panel/memory.py` `usage_view`.

**Fix:** log each malformed entry once, by its text (a price spec, not a secret).

### 14. 🔴 Hermes answers every owner message with a digest (found live by the owner, 2026-10-18)
`agents/herald.py` `answer`; `agents/digest.py` `ASK_BRIEF`; `agents/canon/hermes.md`.

**Scenario:**
- «привіт» or a follow-up in the private room went out with the canon's digest recipe (herald's opening, the main
  threads, a witty signature), two thousand lines of the week, and no line of the chat itself. The model retold Agora.
- It took ~35 s, ~65 s when the old guard regenerated, at ~67k tokens in (≈ $0.2).

**Fix:**
- A message is a conversation: `CHAT_BRIEF` — answer exactly what was written, briefly; Agora only when asked; a
  digest only on «підсумок».
- The private room's last 20 lines as context, read from the homeserver, never kept.
- The canon gains «Як ти говориш з Ich», and its digest recipe is for digests only.
- Thinking `low` for the chat.

### 13. 🟡 Every owner line in the private room is a paid question
`agents/herald.py` `route`.

**Scenario:** «дякую» after a digest costs a Pro call over a week of the room (≈ $0.1).

**Deferred → backlog:** it needs a choice of what counts as a question. A filter could miss a real question, and v5.2
brings voice questions.

## What's solid

- **Agora never hears him.** `send_private` is the only send path and refuses Agora and a missing room. `route`
  only counts Agora's lines, and the speakers never allowlist, name, ask or answer a herald (`speakers()` in every
  pool; the ask draws unchanged for existing events).
- **The first sync is never processed.** The callbacks are registered after it. Only the owner's invite into Agora
  is joined.
- **Secrets and texts stay out of logs.**
  - The ElevenLabs key leaves the environment before any child process starts.
  - Failures are logged by type, status or exit code.
  - A sentinel test proves no text reaches a log.
  - `hermes.env` reaches only his service, and is ignored by git and docker.
- **The voice path matches Element.**
  - `msc3245.voice`, a waveform of 100 values in 0..1024, durations in ms;
  - ffmpeg is killed and waited on after a timeout;
  - nio's `upload` is used as its 0.26 signature expects;
  - checked live: a real Opus encode in the container, and the first digest heard by the owner.
- **Accounting.**
  - Thinking counts as output.
  - Old usage lines still parse.
  - `month_chars` agrees on local months on both sides.
  - Settings saves restart only Hermes for his settings, and never him for the room's.

## Architecture impact

- **The herald's guard is per sentence (#1):** `without_outing` replaces `outs_a_persona` for Hermes — only a
  sentence that ties a persona to a banned word is removed; an empty result is regenerated once, then skipped.
  ARCHITECTURE §The herald says so. The speakers' guard is unchanged.
- **A partial read is never digested (#3)**, and **edits are never new lines for Hermes (#9)**: §The herald.
- **An unknown cost is «—» (#5):** §Token accounting; the panel's usage view gains `default_priced`.
- **The `id` setting kind (#6)** is an ElevenLabs voice id (10–40 letters and digits) or empty — one pattern with the
  voice.
- **A stop drains a running digest (#8)** within compose's 30 s grace period.
- **The private room is a conversation (#14):** an owner message is answered as a chat (`CHAT_BRIEF`, the last 20
  lines of the private room, thinking `low`), not as a question that retells Agora; ARCHITECTURE §The herald.
