## v2.1 — Canons and session memory

### AGORA-016 — Canons: files, loader, persona→canon, prompt with the memory slot
- `agents/canon/common.md` (the room, the owner «Ich», the other agent, Ukrainian, tone) and
  `agents/canon/ada.md` / `bruno.md` (character, voice, interests, attitudes, what they never do) —
  written as **people**; no secrets or private data about the owner (public repo).
- TOML: `canon = "agents/canon/<name>.md"` replaces `persona`; the loader concatenates common + personal;
  missing/empty → `ConfigError` (the bot refuses to start).
- `build_instruction(name, canon, summary=None)`: canon → «Що ти пам'ятаєш з минулої розмови: <підсумок>»
  (only when a summary exists) → the rules line (incl. PASS). No prompt mentions a model or a bot.
- **Tests:** loader (ok, missing, empty), instruction order with/without summary, a guard that no prompt
  text contains model/bot words. **Contract:** the TOML schema `persona→canon` (already specified).

### AGORA-017 — Session memory: timeline, summary call, memory file, idle + graceful shutdown
- Session timeline: every room message since the last summary, apart from `HISTORY_N`, capped by
  `SESSION_MAX_MESSAGES` (hitting the cap triggers an early summary).
- Pure: `session_ended(last_activity_ms, now_ms, idle_ms)`, the summary prompt builder (previous summary +
  timeline → first person, conversation language, ≤ `SUMMARY_MAX_WORDS`), `cap_words`.
- `agents/memory.py`: load (missing → None; corrupt → None + log) / atomic 0600 save of
  `state/<name>.memory.md`.
- Idle watcher task (injected clock) summarizes after `SESSION_IDLE_S` of silence; a failed summary keeps
  the previous file and retries after another idle period; summary texts never logged.
- Graceful shutdown: SIGINT/SIGTERM → stop sync, summarize with a ~20 s timeout, close.
- Startup reads the summary into the prompt (first sync still unprocessed).
- `.env.example`: `SESSION_IDLE_S=900`, `SESSION_MAX_MESSAGES=200`, `SUMMARY_MAX_WORDS=200`.
- **Tests:** session-ended decision, timeline cap → early summary, memory read/write (missing, corrupt,
  atomic, 0600), summary failure keeps the old file, word cap, shutdown summarizes within the timeout —
  Gemini faked, clock injected.
