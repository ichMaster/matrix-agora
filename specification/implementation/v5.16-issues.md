# v5.16 — Issues

Issues for phase **v5.16 — Gemini checks the parts of a blocked prompt** (version **v5 — Voice: Hermes, the agents
hear and speak**), derived from the Tasks and DoD in [ROADMAP.md](../ROADMAP.md) §v5.16 and the contracts in
[ARCHITECTURE.md](../ARCHITECTURE.md). This file covers one phase; ids continue from the previous phase (AGORA-155 →
**AGORA-156…159**).

After a prompt-stage block on Кіра's private prompt, the same model (`GEMINI_REPLY_MODEL`, Gemini 3.1 Pro) gets that
prompt in parts, in the background once the backup has answered. The parts it blocks are closed to it for good
(`censored`), so the same block does not come back at the next message. A fixed layer it blocks is named in the log, and
nothing is closed for it. The phase builds on v5.13 (`blocked_reason`, `LAST_BLOCK`), v5.14 (the route, the backup,
`close_lines`), v5.15 (the judge, `_blocked_items`, `judge_later`) and v5.15.4–v5.15.5 (`GEMINI_CLOSED`, `next_mark`).

**Owner decisions** (2026-10-31, confirmed at generation):
- The probe replaces the judge's rating of the blocked prompt's lines at a prompt-stage block. The judge still rates the
  backup's talk.
- The caps are `PROBE_CALLS` 12 per block and `PROBE_DAY_CALLS` 60 per day.
- The probe uses the blocked call's model (3.1 Pro), not Flash.
- What it blocks is closed `censored`.

**Reconciled with the code** (2026-10-31, after `7454afe`):
- **The block:**
  - a block is `LAST_BLOCK` = `(stage, reason, category)`, set by `GeminiClient.reply`/`complete` through
    `_empty` → `blocked_reason`;
  - the prompt stage is any `prompt_feedback.block_reason`.
- **Building the prompt:**
  - `_gemini_text(brief, kind, used)` builds the prompt with `_gemini_private_prompt(brief, used)` and the history with
    `gemini_history()`;
  - `build_prompt` passes its layers to `build_instruction` (`agents/logic.py`) as keyword sections;
  - the recall (`recall_section(..., used=)`) renders groups of lines with neighbours (`render_recalled`), a fact or a
    thought alone;
  - the pinned facts come from `facts_section` (`agents/facts.py`), today's thoughts from `thoughts_section`
    (`agents/thoughts.py`) over `day_thoughts`;
  - the transcript is `build_transcript(lines)` (`agents/responder.py`).
- **The judge at a block:** `_private_text` returns `("block", his + self._blocked_items(used))` as `judge_after`, and
  `private_reply` spawns `judge_later` once her line is sent.
- **The route file:** it already carries the day's counters (`judged`).
- **Usage kinds:** `KINDS` in `agents/usage.py`.
- **Settings:** the registry in `agents/settings.py` (`_s(...)`, group `fallback`, `cap:fallback`).

## v5.16 — Gemini checks the parts of a blocked prompt

### AGORA-156 — The search: the smallest blocked set (`agents/probe.py`)

**Description:**
A new module `agents/probe.py` holds the search over a blocked prompt's parts: a driver over an injected async oracle
(`blocked(keep_items, keep_layers) -> bool | None`). It is pure apart from the awaited oracle, so tests drive it with a
fake that blocks a prompt holding given items.

**What needs to be done:**
- **The data:** item ids are opaque strings, and layer names come from the caller. The result is `Found(calls, closed:
  tuple[str, ...], layers: tuple[str, ...], outcome)`, where `outcome` is one of:
  - `not_reproduced`;
  - `base_blocks`;
  - `found`;
  - `cap`;
  - `error`.
- **The steps**, under one budget of `cap` oracle calls:
  1. **The whole prompt** (every item, every layer). If it passes, return `not_reproduced` and close nothing.
  2. **The base:** every layer and no item. If it blocks, the cause is a layer. Search the layers the same way, with an
     empty set of layers as the base, and return `base_blocks` with the smallest blocked set of layers. Close nothing.
  3. **The items,** by delta debugging, each set tried as base + the set, down to a 1-minimal blocked set. Return
     `found` with that set. *(As built: QuickXplain, which assumes the filter blocks more as more is added. It takes
     at most 12 calls for one item among 40 and 15–19 for a pair; ddmin took 42 for a pair.)*
  4. **At the cap:** if the budget runs out first, return `cap` with the smallest blocked set found so far. Every set the
     search holds is one that was seen to block, so closing it always removes a blocked combination. *(As built: never
     the whole item set. With nothing narrowed, `cap` closes nothing, since closing every item would close all she
     knows to Gemini.)*
- **Errors:** an oracle answer of `None` (an error) stops the search with `error` and closes nothing.
- **No text:** nothing about an item's text enters the module, only ids.

**Dependencies:** None

**Expected result:**
Given a fake oracle, `search(...)` returns the smallest set of items (or layers) whose presence blocks, within the cap.

**Acceptance criteria:**
- [ ] One blocking item among 40 is found, and the calls stay within 12.
- [ ] Two items that block only together are both found, and neither alone.
- [ ] A blocking layer: `base_blocks`, the layer named, no item closed.
- [ ] Not reproduced: one call, nothing closed.
- [ ] The cap reached: `cap` with a set the oracle saw block.
- [ ] An oracle error: `error`, nothing closed.
- [ ] **Tests:** `tests/test_probe.py`, with a fake async oracle and no network.
- [ ] **Gates:** lint, tests.

### AGORA-157 — The probe call and its usage kind `probe`

**Description:**
`GeminiClient.probe` (`agents/llm.py`) sends one prompt to the reply model only to read the prompt-stage verdict. Its
usage line is a new kind, `probe` (`agents/usage.py`).

**What needs to be done:**
- `async def probe(self, transcript, system_instruction, kind="probe") -> bool | None`:
  - **The call:** `self.reply_model`, with `max_output_tokens=1` and the lowest thinking setting the model takes (a
    thinking model: `thinking_level` low; any other: `thinking_budget=0`); automatic function calling off.
  - **The answer:** `True` when `blocked_reason(resp)` has stage `prompt`, `False` for anything else (an answer, a
    `MAX_TOKENS` finish, an answer-stage block, an empty answer), and `None` when the call raises.
  - **Never** sets `LAST_BLOCK` (an answer in the same task must not read a probe's block) and never logs a text. One
    line per probe: `probe: blocked` / `passed` / `failed (<type>)` at debug level.
- **Usage:**
  - each probe reports through the sink as kind `probe` on the reply model, with `blocked="prompt"` when blocked;
  - `KINDS` gains `probe`.
- **ARCHITECTURE §Token accounting:** a sentence on the kind `probe` (v5.16), on the reply model, priced by its pair in
  `PRICE_MODELS`.

**Dependencies:** None

**Expected result:**
A probe call answers whether Gemini blocks a prompt at the prompt stage, and every probe is counted under `probe` in the
token report.

**Acceptance criteria:**
- [ ] Blocked at the prompt stage → `True`, with a usage line `probe` and `blocked: prompt`.
- [ ] A normal answer, a `MAX_TOKENS` finish or an answer-stage block → `False`.
- [ ] An exception → `None`, with a usage line `ok: false`.
- [ ] `LAST_BLOCK` is unchanged by a probe.
- [ ] The request carries one output token and the low thinking level on 3.1 Pro.
- [ ] **Tests:** `tests/test_llm.py` (or a new `tests/test_probe_call.py`) with a fake `genai` client.
- [ ] **Contract:** the usage kind `probe` — `KINDS` and its pinning test, and ARCHITECTURE §Token accounting.
- [ ] **Gates:** lint, tests.

### AGORA-158 — Her private prompt in parts: captured, rebuilt from what is kept

**Description:**
Her private prompt for Gemini is captured as layers plus the closable items, each item with its key. It can be rebuilt
from any kept subset, and rebuilt whole it is the very prompt that was sent (`agents/agent.py`, `agents/logic.py`).

**What needs to be done:**
- **`prompt_layers(...)`:** split `build_prompt` into `prompt_layers(...) -> dict` (the keyword sections it hands to
  `build_instruction`) and `build_instruction(**layers)`. Behaviour is unchanged: every existing prompt test stays green.
- **The snapshot:** `_gemini_private_prompt(brief, used, parts=None)` fills `parts` (a `PromptParts`) when given, and
  `_gemini_text` passes it through. The snapshot holds:
  - `layers`: the fixed sections, by name (canon, summary, life, world, memories, plans, today, mood, asked, private,
    agora_now, voice and the rest `build_instruction` takes), with the closable sections (`recalled`, `facts`,
    `thoughts`) set aside;
  - `items`, each with an id (`line:<key>`, `fact:<id>`, `thought:<key>`):
    - the open history lines the transcript held (`archive.latest("private", history_n)` minus `_closed`, with their
      keys);
    - the recalled groups (each line with its key; a fact by its id, a thought by its key);
    - the pinned facts `facts_section` chose;
    - today's thoughts `thoughts_section` rendered (their `thought_key`s).
- **The rebuild:** `PromptParts.render(keep_items, keep_layers) -> (system, transcript)` builds the instruction from the
  kept layers, and from the recall, facts and thoughts sections re-rendered from the kept items by the same renderers
  (`render_recalled`, `facts_section`, `thoughts_section`). The transcript is `build_transcript` of the kept history
  lines.
- **No text** of the snapshot is logged or written to disk; it lives in memory until the probe ends.

**Dependencies:** None

**Expected result:**
`render(all items, all layers)` equals the system instruction and transcript of the blocked call, and any subset renders
without the left-out parts.

**Acceptance criteria:**
- [ ] `build_prompt` gives the same text as before for Agora and private prompts (existing prompt tests unchanged and
      green).
- [ ] The whole snapshot renders byte for byte as the prompt and transcript Gemini got.
- [ ] Leaving out a history line, a recalled line, a fact or a thought removes exactly it. A recalled group without its
      line keeps its other lines.
- [ ] Leaving out a layer removes its section.
- [ ] **Tests:** with the Gemini fake capturing the call's system and contents, and made-up lines only.
- [ ] **Gates:** lint, tests.

### AGORA-159 — The probe after a prompt-stage block: the caps, the closing, the judge's share

**Description:**
This issue wires the search (AGORA-156), the probe call (AGORA-157) and the prompt in parts (AGORA-158) into her private
answer, with the per-block and per-day caps, the closing, the log, and the judge's share at a prompt-stage block
(`agents/agent.py`, `agents/route.py`, `agents/settings.py`).

**What needs to be done:**
- **When:** a block at the stage `prompt` on `private` or `private_nudge`, on the route `gemini` and at the window's end
  (both with and without the judge).
  - **When it runs:** `private_reply` spawns `probe_later(parts)` once her line is sent, or once the backup gave none,
    like `judge_later`, behind its own `_probe_lock`. It is never on the reply path, and the route and the window stay
    as they are.
  - **Never** after an answer-stage block, a refusal, an Agora call or a background call.
- **The oracle:** `blocked(keep_items, keep_layers)` = `llm.probe(*parts.render(keep_items, keep_layers))`.
- **The caps:**
  - `PROBE_CALLS` (12) per block and `PROBE_DAY_CALLS` (60) per day: the search gets `min(PROBE_CALLS, left today)`;
  - 0 for either turns the probe off;
  - the day's count lives in `state/kira.route.json` as `probed: {"calls": n, "closed": m}`, reset with her day like
    `judged`. `route_after` takes an outcome `probed` with the counts.
- **Closing** (`outcome` `found` or `cap`): each closed id becomes `censored`.
  - a line or a thought: `archive.mark(keys, "censored")` (its vector dropped), then `close_lines` for a private line;
  - a fact: `set_fact_mark(..., "censored")`, then `facts_now()` so the archive's mirror follows;
  - it overrides a `clean`, and only closes (v5.15.5's rule holds).
- **The judge's share:** at a prompt-stage block, `judge_after` is `("block", his)` without `_blocked_items(used)`. The
  judge still rates his line and her backup answer. At an answer-stage block, nothing changes.
- **The log:** counts and layer names only, never a key or a text:
  - `probe: N calls — closed X lines, Y facts, Z thoughts`;
  - `probe: the base blocks — layers <names>`;
  - `probe: not reproduced (N calls)`;
  - `probe: stopped — <outcome>`;
  - `probe: off — the day's calls are spent`.
- **Settings:**
  - `PROBE_CALLS` and `PROBE_DAY_CALLS` in the registry (`agents/settings.py`, group `fallback`, `cap:fallback`, 0–50 and
    0–500);
  - read in `Agent.__init__` with the backup;
  - `kira.env.example` names them only if it lists the backup's settings.
- **ARCHITECTURE:**
  - §Memory: the probe, beside the verdicts;
  - §Configuration: the two settings;
  - §Contracts: the route file's `probed`.

**Dependencies:** AGORA-156, AGORA-157, AGORA-158

**Expected result:**
After a prompt-stage block, her backup answers as before. Then Gemini is probed in the background, and what it blocks is
`censored` and gone from her next prompt to Gemini.

**Acceptance criteria:**
- [ ] A prompt-stage block with one blocking recalled line: after the backup's line is sent, the probe closes that line
      `censored`, and her next Gemini prompt holds it nowhere (history, recall).
- [ ] The same for a fact (the facts section and the archive's mirror) and a thought (today's thoughts).
- [ ] A blocking layer is named in the log, and nothing is closed.
- [ ] No probe after an answer-stage block or a refusal, in Agora, or in a background call.
- [ ] The probe starts only after her line is sent: the order of calls shows the send, then the probes.
- [ ] The caps: per block, per day (counted in the route file across a restart, reset with the day), and 0 = off.
- [ ] At a prompt-stage block the judge rates only his line and her backup answer. At an answer-stage block, as before.
- [ ] A probe error closes nothing.
- [ ] No text or key in a log.
- [ ] **Tests:** the private route with the Gemini fake (a prompt-stage block when the prompt holds a marker, probe
      calls answered the same way), the backup fake and the judge fake; an injected clock; made-up lines only.
- [ ] **Contract:** `state/<name>.route.json` gains `probed` — `tests/test_route.py`'s key set and ARCHITECTURE
      §Contracts; the settings in ARCHITECTURE §Configuration.
- [ ] **Gates:** lint, tests.
- [ ] **Manual (owner):** after a live prompt-stage block, the log shows the probe's line with its calls and what it
      closed (or the layer it named), and his next message, or her next line written first, is not blocked by the same
      items.
- [ ] **Manual (owner):** the day's probe calls are in the token report under `probe`, within `PROBE_DAY_CALLS`.
