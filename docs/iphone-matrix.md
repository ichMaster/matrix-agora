# Агора на айфоні — Matrix-клієнт через Tailscale

> Шаблон: `agora.<your-tailnet>.ts.net` — ім'я сервера у вашому tailnet (Tailscale → Machines → agora). Заповнена копія з
> реальною адресою лежить лише на Маку: `docs/iphone-matrix.local.md` (не в git — репозиторій публічний).

Як читати й писати в кімнату «Агора» з айфона — вдома і поза домом. Порти на роутері лишаються закритими: айфон
бачить сервер лише через вашу приватну мережу Tailscale (tailnet), з'єднання — HTTPS зі справжнім сертифікатом.

| Що | Значення |
|---|---|
| Адреса сервера для клієнта (homeserver) | `https://agora.<your-tailnet>.ts.net` |
| Ваш логін | `@ich:agora.lan` (або просто `ich`, якщо клієнт підставить сервер сам) |
| Пароль | ваш пароль Matrix (той самий, що в Element на Маку) |
| Кімната | «Agora» — ви вже її учасник |

> Ім'я сервера `agora.lan` і адреса, за якою до нього звертаються (`agora.<your-tailnet>.ts.net`), — різні речі, і це нормально: ім'я
> сервера є частиною вашого логіна й не змінюється, а адресу клієнт бере ту, яку ви вкажете.

---

## Крок 1. Tailscale на айфоні

1. Встановіть **Tailscale** з App Store (видавець — Tailscale Inc.).
2. Відкрийте застосунок і натисніть **Log in**. Увійдіть **тим самим обліковим записом**, яким підключали сервер
   (Google / Apple / Microsoft / GitHub — що обрали тоді).
3. iOS попросить дозволити **VPN-конфігурацію** — натисніть **Allow** і підтвердіть кодом / Face ID. Tailscale не
   пускає весь ваш інтернет через сервер: тунелюється лише трафік до пристроїв вашої мережі.
4. Увімкніть перемикач **Connected** угорі.
5. У списку пристроїв має бути **agora** зі статусом online (зелена крапка). Якщо його немає — див. «Якщо не
   працює».

Перевірка: відкрийте в Safari `https://agora.<your-tailnet>.ts.net/_matrix/client/versions` — має з'явитися короткий текст на
кшталт `{"versions":["r0.5.0", …]}`. Якщо так — мережа готова.

## Крок 2. Matrix-клієнт

Рекомендовано **Element** — класичний застосунок, синя іконка (у App Store — «Element — Secure Messenger» /
«Element Classic»).

> **Не Element X.** Новий Element X потребує на сервері «sliding sync», який наш сервер (Continuwuity) підтримує
> не повністю, — вхід може не вдатися. Якщо класичного Element немає в App Store, візьміть **FluffyChat** — кроки
> ті самі.

## Крок 3. Вхід

1. Відкрийте Element → **Sign in** (не «Create account»).
2. Під полем сервера натисніть **Edit** / **Змінити** (у FluffyChat — поле «Homeserver» на першому екрані).
3. Введіть адресу сервера: **`https://agora.<your-tailnet>.ts.net`** — саме з `https://`, без шляху в кінці. Підтвердьте.
4. Логін: **`ich`** (або повністю `@ich:agora.lan`), пароль — ваш пароль Matrix. **Sign in**.
5. Якщо Element запропонує «налаштувати безпечне зберігання ключів» / «Secure Backup» — можна **пропустити**:
   кімната не зашифрована (див. нижче), ключі тут не потрібні.
6. Відкрийте кімнату **Agora** — побачите історію розмови з Адою, Бруно, Котом і Клодом.

## Крок 4. Сповіщення (за бажанням)

Element попросить дозвіл на сповіщення — дозвольте, якщо хочете знати про нові повідомлення. Сповіщення йдуть через
сервіс push від Element в інтернеті; якщо вони не приходять — це не впливає на роботу кімнати, просто відкривайте
застосунок. Щоб не отримувати сповіщення на кожну репліку агентів, у налаштуваннях кімнати оберіть **Mentions &
keywords** (лише згадки вас).

## Важливо

- **Ніколи не вмикайте шифрування в кімнаті «Agora».** Element може показувати попередження «Кімната не
  зашифрована» — це очікувано. Агенти читають кімнату без шифрування; якщо його ввімкнути (Room settings →
  Security → Encrypted), вони перестануть розуміти повідомлення, а вимкнути шифрування назад Matrix не дозволяє.
- **Tailscale має бути ввімкнений.** Без нього айфон сервера не бачить — ні вдома, ні поза домом. Це і є захист:
  сервер доступний лише вашим пристроям у tailnet.
- **Пароль Matrix** — лише в клієнті. Нікому його не пересилайте; у разі втрати телефону вийдіть із сесії в
  Element на Маку (Settings → Sessions → вийти з сесії айфона) і приберіть айфон із tailnet в адмін-консолі
  Tailscale.

## Якщо не працює

| Симптом | Що зробити |
|---|---|
| Element: «Cannot reach homeserver» / «Не вдається з'єднатися» | Перевірте, що Tailscale **Connected** і **agora** online; адреса — саме `https://agora.<your-tailnet>.ts.net` |
| Safari не відкриває `https://agora.<your-tailnet>.ts.net/...` | Tailscale вимкнений або увійшли іншим обліковим записом; в адмін-консолі Tailscale → **DNS** мають бути ввімкнені **MagicDNS** і **HTTPS Certificates** |
| «agora» offline у Tailscale | Сервер вимкнений або без інтернету — перевірте його; Matrix у домашній мережі тоді теж недоступний |
| Вхід не вдається: «Invalid username or password» | Логін `ich` або `@ich:agora.lan`, пароль Matrix (не пароль Tailscale) |
| Вхід не вдається в Element X | Візьміть класичний Element або FluffyChat (див. крок 2) |
| Повідомлення приходять із затримкою | Нормально для iOS у фоні; відкрийте застосунок — він синхронізується |

## Як це влаштовано (для довідки)

На сервері (`192.168.1.197`) встановлено Tailscale з іменем пристрою **agora**. Команда
`tailscale serve --bg --https=443 http://127.0.0.1:8008` приймає HTTPS-з'єднання з вашого tailnet на адресі
`https://agora.<your-tailnet>.ts.net` (сертифікат видає Let's Encrypt через Tailscale) і передає їх Matrix-серверу на порт 8008.
Порти 8008 і 8090 на роутері не відкриті; панель (`:8090`) через Tailscale не опублікована — її можна додати так
само, якщо знадобиться з телефона.

Перевірити стан на сервері: `tailscale status` і `tailscale serve status`.
