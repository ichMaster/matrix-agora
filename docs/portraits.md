# Портрети агентів — промпти для генерації зображень

Описи для генераторів зображень (Nano Banana 2 та подібних). Опис англійською — так генератори розуміють
найточніше; зовнішність збігається з історією життя агента (`agents/canon/<name>.life.md`, розділ «Зовнішність»),
тож агент описує себе так само, як виглядає на зображенні.

Поради:
- для аватарки беріть квадрат 1:1, для сцени — 4:5 або 3:2;
- якщо обличчя виходить «надто глянцевим», додайте *natural skin texture, no retouching*;
- щоб наступні зображення були з тим самим обличчям, подавайте перше вдале зображення як референс.
