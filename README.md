# matrix-agora

A private Matrix room where a human and two small LLM agents (Gemini 2.5 Flash) talk together. A self-hosted [Continuwuity](https://continuwuity.org) homeserver on the LAN, Element Desktop as the client, and Python agents built on `matrix-nio` + `google-genai`.

Status: proof of concept. See [specification/SPEC.md](specification/SPEC.md) for the phased plan (Ukrainian original: [SPEC-UA.md](specification/SPEC-UA.md)).
